# ADR 0006：去过、抽象世界地图与真实照片地图

状态：产品方案已确认，2026-09-12；区域视觉样稿已获确认；完整地图与 OSM 业务已接入，Google/高德待真实 Key 联调。

## 已接受的需求

用户确认导航增加“去过”，保留相册、相片、关于；本决策替代 ADR 0002 中地图暂缓的范围决定，其余决定不变。

世界总览使用原创抽象 SVG，默认中国居中。未去过国家白色，去过国家统一强调色；海洋及重要海域保留浅蓝留白与名称。大国轮廓面积总体大于小国，不按实际面积等比例缩放；小国应有可读名称。国家相对方位、接壤、海峡及岛屿关系优先于铺满画面。相邻国家共用边界，不以独立描边掩盖几何重叠。减少无谓折线，支持缩放和平移。

参考 vision-ke“接替codex cli开发”、tickoff“设计世界地图打卡标记APP”中的原创原型和用户反馈；world-ex 仅为表达参考，不复制代码、坐标或 SVG。先审查高加索、黑海、里海和中东区域，再扩展世界。区域样稿中的大国被画框裁切，不能据此验收全球面积比例或完整国家清单。

## 统计和权限

用户明确确认：只统计已发布到 Gallery、当前有效且允许公开位置的照片。不得从全部 Immich 照片推导私人旅行信息。

- 使用现有 published_photo 授权边界，包括发布祖先链、当前版本、来源白名单、Asset 状态和衍生图资格。
- 全站先按 Asset 去重，同 Asset 的允许位置出现采用较保守模式；隐藏位置不参与。三张照片组成一组仍计三张。
- 原始 GPS 仍以 Immich 为准。国家归属使用版本固定的真实边界数据，不用抽象 SVG 或可能过时的 EXIF 国家文字。
- 近似位置先在服务器处理，再用于公开筛选、聚合。近似网格跨国界时国家归属不能额外暴露精确位置，应标记待核对并暂不归国，不擅自选择最近国家。地图照片总量与已归国照片总量分别标注。
- GPS 清空、修正、撤回发布、祖先下线、来源资格改变均在下一次请求反映。缓存不作为授权依据，失效需覆盖 Asset 与 EXIF 独立变化以及删除。

## 到访记录

用户明确确认：自动推导并允许后台人工校正。照片日期是拍摄证据，不冒充准确出入境日期。

初始建议规则为同国照片相隔超过 30 天拆分；两段之间有其他国家的可靠拍摄记录时可拆分。阈值可配置。使用可靠拍摄时刻排序、当地日期展示，不用加入 Gallery 的时间代替。时间或时区证据不足时明确标注未知，不凭浏览者时区猜测。自动算法及校正的冲突处理在数据实现阶段验证。

管理员可合并、拆分、修正到访日期。校正只改变 Gallery 到访组织，不改 Immich 元数据，不新增访问权限；证据照片失效时重新核对，无有效公开证据的记录不公开。公开摘要显示时间段、照片数量和“根据照片拍摄时间整理”。

## 前台交互

桌面悬浮或键盘聚焦国家展示摘要，点击进入国家真实地图。触摸屏首次点选显示底部面板，明确按钮进入照片地图；平移和缩放不能误触国家。未去过的国家不进入空的照片地图。

真实地图支持聚合数量、放大展开、同点照片列表、到访筛选和现有照片组大图查看器；返回保留地图状态。国家地图直接展示真实底图，本轮不增加省份打卡中间层或路线规划。

## 地图服务

默认 OSM；可选 Google Maps 与高德。MapLibre/OSM、Google Maps JavaScript API、高德 JS API 通过适配层共用相同的 Gallery 数据和视图状态。切换保留地区、照片与筛选，只加载所选服务。

内部 GPS 统一 WGS84，高德国内展示按官方 GCJ-02 要求转换；不覆盖原始 GPS。视口查询也需处理坐标体系和跨日期变更线。国内、海外控制点分别验证，不直接拼接未知来源瓦片地址。照片聚合在 Gallery 内完成。

后台配置启用状态、默认服务、公开浏览器 Key、私有安全密钥及检测结果。浏览器 Key 使用来源/API 限制；高德安全密钥经服务端代理，不混入公开站点配置。未配置服务前台不显示，不可用服务提示切换。Google/高德需实际授权 Key 联调，不以配置页存在冒充完成。

官方核对入口（2026-09-12）：
