# ADR 0010：统一照片资料与标签

状态：用户已确认开发，2026-09-12；实际迁移和验证另记。

同一 Immich Asset 对应一份 Gallery 照片资料。标题、Markdown 描述、替代文本及标签统一维护；相册只维护收录、排序、封面、照片组和位置公开约束。替代 ADR 0001/0004 的按相册独立照片资料规则。

照片资料具有统一草稿与独立不可变发布版本。从任意相册保存草稿后，其它相册编辑界面读取同一草稿；发布后所有公开引用读取同一照片发布版本，不发布其它相册的组织修改。相册完整发布会发布本册引用的统一资料草稿。下线相册不会被照片发布恢复。组内仍展示组标题/说明，标签与 EXIF 属于成员。EXIF 统一快照、拍摄时间与 GPS 读取来源；每个相册的 EXIF/位置隐私约束继续生效。

新增统一标签管理：创建、去重、重命名、停用、删除无引用标签；已有引用不因停用消失。标签名称统一实时显示，关联走照片发布。编辑照片可以多选标签和快捷创建，组编辑提供批量添加/移除。

前台相片页多标签取交集，与排序、年月和分页同时使用，地址保留条件。计数与标签候选仅来自可公开照片，按 Asset 去重。详情标签链接进入对应筛选，沉浸时隐藏。

新增 Gallery 表和受控视图，不修改 Immich。迁移前检查跨相册文字冲突，真实冲突经用户选择后才应用；保留旧相册草稿字段与历史快照作为可追溯来源。已有标签为空。并发编辑必须校验统一照片版本，避免另一相册旧表单覆盖新资料。
