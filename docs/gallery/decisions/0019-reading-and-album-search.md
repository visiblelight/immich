# ADR 0019：图文阅读、相册搜索与来源选片

状态：用户于 2026-10-17 确认；实际实施与验证见[交付记录](../delivery/reading-and-album-search.md)。

## 已确认范围

- 文章正文整体加宽，文字、单图和图片组使用同一内容栏和左右边界；不做图片向外突出的布局。照片完整显示，竖图可居中并限制高度，桌面目录保持独立。
- 手机及窄屏目录使用常驻吸顶入口，显示当前章节；展开为有高度上限、可独立滚动的浮层，选择章节后收起，标题避免被导航遮挡。
- 照片拍摄位置各级名称使用相同字号与字重，保留轻量层级分隔和点击筛选。
- 前台相册页加入关键词检索，覆盖相册标题、摘要、介绍，所含公开照片及照片组的标题/描述，以及规范地点的中文、英文与别名。匹配已公开子相册内容时，父相册也可被找到；进入相册后保持完整正常内容。搜索与排序并列，查询保留在 URL。
- 搜索只能使用合资格发布数据。草稿、仅文章可见照片、失效来源和下线分支不能贡献搜索结果。位置遵循既有隐藏/近似策略，跨相册同源照片采用较保守策略，GPS 仍实时来自 Immich。
- Immich 选片左侧增加来源相册搜索，右侧显示当前来源；切换使用整体加载状态、回到顶部、阻止过期请求覆盖当前结果，保留跨相册选择。
- 去过页国家条目紧凑排列，国家名称与记录/照片数量相邻并垂直居中，适配桌面多列和手机单列。

## 2026-10-17 视觉修订

用户确认以此替代上文国家条目的单行排列：相册标题与数量独立在左，右侧使用紧凑搜索框与排序下拉；移除单独搜索按钮，输入停顿后自动检索，回车立即提交，提供清除入口。手机端标题独占一行、工具栏在下一行。国家条目采用国家名在上、统计在下的两行布局，适中固定列宽，手机两列；取消大块悬停底色，以国家名称变色反馈。

后续用户要求相册排序与相片页保持一致，替代上述排序下拉方案：两项并列分段控件，浅底容器、白色选中项，统一字号、圆角与选中阴影；保留右侧搜索工具栏。
