# ADR 0011：内容优先的前后台布局

状态：已确认。2026-09-13 用户确认视觉审查方案并授权实施。

## 决定

- 前台共用页头、导航尺寸、字体与背景；稳定滚动条占位，避免跨页位移和全局样式相互覆盖。
- 移除装饰英文标题，目录采用紧凑中文标题与数量；关于保留文章阅读层级。完整中英切换另行实现。
- 相片页桌面左侧集中排序、时间、标签；右侧直接展示照片。窄屏收为可展开筛选入口，默认照片优先。
- 相册详情中，同时有照片的子相册采用紧凑入口；纯父相册保留子相册网格。
- 地点与 EXIF 默认展开，区分人工说明与拍摄资料；去掉照片直链按钮，保留地址和沉浸查看能力。
- 后台相册编辑默认照片标签，子相册独立标签；发布概况按需展开。保持现有草稿与发布边界。
- 照片卡片以图片为主，选择与拖动工具叠放在图角；其它操作收进菜单。选中后展示批量工具栏，保留键盘与菜单排序方式。
- 照片组弹窗保留照片在顶部，去掉重复标题、冗余空间；统一表单间距和按钮层级。
- 站点保存操作放在完整表单末尾，联系链接独立分区并明确保存范围。

本轮不变更数据库、照片统一资料、发布权限或 Immich 集成。

实际实现与验证见 [交付记录](../delivery/content-first-visual-layout.md)。旧设计文档保留历史背景，以本决定为当前视觉方向；完成开发不代表最终视觉验收。
