# ADR 0003：功能 MVP 的发布动作与文字编辑

日期：2026-09-11。状态：随用户“暂缓视觉细节、继续完成大闭环”的指示实施；不扩大首页、地图或文章模块范围。

后台设计已经区分“恢复公开版本”与“发布新版本”。真实业务保留此区分：恢复重新开放原快照，发布才把已保存草稿复制为新快照。两个动作都重新校验父链；恢复父级不改变手动下线子级的状态。原 publication 文档仅允许重新发布的段落由此替代。

MVP 使用支持段落、小标题、引用的文字块编辑器，服务端拒绝图片和任意 HTML；不引入尚未需要的富文本依赖。它满足游记正文和照片分开的布局，行内样式／链接以后扩展。已发布相册只下线；从未发布且无子级的草稿可以确认删除，Immich 原片不受影响。

登录与密码修改增加持久化限流表 0003。前后台均采用各自最小权限数据库角色，管理员会话仅在后台认证；公开页面和媒体每次读取当前发布资格，图片重编码移除源文件元数据。

当前为可使用的本地 Node 构建 + 现有 Immich Docker 开发环境。独立 Compose 打包、生产 TLS／代理设置、上游升级及完整恢复演练仍按阶段 F 单独验收，不以本地流程通过替代生产验收。
