# ADR 0027：位置变化后的时间更新状态

状态：2026-11-01 用户确认优化状态及自动刷新，先本地实现与验证。补充 ADR 0025/0026；不修改时间换算证据规则。

- Immich 时间或 GPS 变化后，旧结果失效属于“正在更新拍摄时间”，不计入人工待核对。已打开的管理页自动发现变化，请求现有读取队列，完成后刷新列表。
- 页面可见时定期检查；更新中加快检查，切回页面立即检查。隐藏页面、编辑确认弹窗及正在提交时暂停检查，避免打断输入。不无限重复提交自动读取。
- 读取失败或超时显示“更新失败，可重试”，与时间证据不足或冲突区分；确认时间仍需绑定最新来源与证据版本。
- 无有效位置但具有相机钟表的照片保留原始时间，不因地点未知增加人工待办。已知相机 UTC 偏移保留；使用“拍摄地时区未知”，不要求维护“待补充地点时区”。没有相机钟表、时间证据冲突等仍可核对。
- 自动处理继续写 Gallery 的证据与现有队列，原片、Immich 元数据、内容关联、既有人工决定保护规则不变。不开新权限，不新增数据库迁移。
