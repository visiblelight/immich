# ADR 0007：后台导航、作品统计与位置默认值

状态：用户已确认，2026-09-12。实际交付另记。

- 相册总览显示当前草稿的相册数、照片数、照片组数。全站照片按Immich Asset去重；组成员仍计入照片数，组数另列。相册行和编辑页分别显示本册直接照片、照片组、子相册数量，不把后代照片再次混入本册计数。
- 移除左侧最近相册列表。相册、到访记录、地图设置、站点设置共用稳定侧栏，顺序一致；前台入口和账号入口保留。站点设置成为独立URL，账号入口不作为第五个业务一级导航。
- 相册列表用父子缩进、展开／收起体现草稿层级；搜索和筛选保留命中项的祖先路径，路径行有区别，并自动展开。
- 照片组编辑弹窗中，照片、排序、封面与成员选择置于标题和共用说明之前，保持既有草稿／单项发布语义。
- 新建相册的应用默认值改为精确位置，照片仍默认跟随相册。替代ADR0001及需求基线中的“新相册默认隐藏”。已有相册、照片和发布快照不修改。数据库列的防御性hidden默认保留，创建服务显式写入exact，无需数据库迁移。
- 未去过国家无悬浮摘要、无点击选中上色、无可点击手势和键盘按钮入口；区域样稿与正式世界图同步。地图整体平移缩放保持。
