# ADR 0004：Markdown、照片组与全站相片

状态：用户已确认，2026-09-11；实现及验收结果另记。

相册正文、照片说明和组说明使用 Markdown 原文，保存在 Gallery 数据库与不可变发布快照中；提供工具栏、预览、全屏和 .md 导入导出，不支持内嵌图片或原始 HTML。可选摘要用于列表及 SEO，没有摘要时提取正文。旧内容只读转换，保存后升级格式，不改写历史快照。

照片组属于单一 Gallery 相册，无嵌套；有标题、共用说明、封面，成员保留原说明、画面描述和独立元数据。组及成员排序在草稿保存后持久化，发布后生效；组成、解散不得丢失文字。解散时共用说明保留到成员。

相册左右切换项目，组算一个项目；上下键或缩略图切换成员，放大时方向键移动画面。移动端左右滑动切项目，组内用缩略图。全站相片页按每张照片展平、按 Asset 去重；默认拍摄时间倒序，可切首次加入 Gallery 时间倒序，年月定位，未知日期独立分组。默认选最早首次公开且当前可见的相册出现位置作为说明上下文，完整使用该上下文权限，不混用元数据；提供其他当前公开相册入口。

加入时间由服务端首次保存记录，全局同 Asset 保持稳定，不因保存、重发、移除再加而刷新。历史加入时间无法精确还原，使用现有记录中的较早时间并标记估算。未知拍摄日期不以加入日期冒充。GPS 仍实时读取，标题、描述、EXIF 仍为发布快照。

元数据显示分成作品说明、拍摄日期/位置及折叠拍摄参数；坐标仅按已有公开策略返回。辅助字段移入高级设置。迁移只添加 Gallery 对象及受控视图，不修改 Immich。上线前做备份、隔离迁移及权限/快照/直链回归。导航增加相片；首页和地图仍暂缓。
