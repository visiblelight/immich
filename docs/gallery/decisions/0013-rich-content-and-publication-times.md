# ADR 0013：完整富文本、发布时间与配置归属

状态：2026-09-14 用户确认实施。实际交付另记，不将批准视为已完成。

- 在既有结构化文章上增加表格（表头、行列操作、合并拆分）、任务清单（含嵌套与完成状态）、下划线、删除线、单色高亮、行内代码及代码块；编辑、粘贴、服务端校验、预览、发布渲染保持一致。
- 表格手机端局部横向滚动。任务状态由作者编辑，前台只读。排版统一，不导入外部任意 CSS、字体或脚本。
- 粘贴尽量保留支持的结构，对不支持内容和未导入图片提示；外链图片显示可替换占位，图库选片／素材上传后替换，不直接授予远程 URL 媒体权限。正文 H1 转为 H2，文章主标题仍独立维护。
- 关于选篇仅放站点设置，移除文章列表的配置控件。
- 首次发布时间取第一条发布记录，最近更新时间取当前发布版本的发布时间；保存草稿、下线不改变公开时间。前台只有后续发布时显示更新，列表按首次发布倒序。可手填的 date 保留并标为写作日期，不伪装为实际发布时间。
- 后台导航和页面标题明确使用“照片标签”，照片编辑与前台筛选内部的“标签”用语不必重复前缀。
- 既有已丢失的粘贴结构不能凭空恢复，用户需要重新粘贴原文。旧文章 JSON 保持可读；新增节点由新版校验和渲染处理。
