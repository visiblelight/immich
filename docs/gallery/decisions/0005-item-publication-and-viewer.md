# ADR 0005：照片组浏览、当地时间与单项发布

状态：用户已确认，2026-09-12。实际验收另记于交付文档。

## 作品说明与编辑

组成照片组后，前台只展示组标题与 Markdown 共用说明；组说明为空也不回退到个人说明。保留个人文案，移出／解散后重新使用；解散时继续保留共用文案。成员各自的无障碍文字、拍摄时间、EXIF 和允许公开的位置不合并。

添加／编辑照片组进入独立大弹窗，移动端全屏。弹窗使用编辑副本；取消不修改相册，有未保存修改时提示放弃。照片及照片组提供“保存草稿”和“保存并发布”，组成员设置不再展示个人作品说明编辑框。

## 浏览导航

相册大图左侧为组内垂直缩略图，上下切换成员；底部为同相册照片／照片组横向缩略图，左右切换项目。选中项明显标记并滚动到可见位置。手机保留可收起的左侧视角栏，说明在图片下方。放大后方向键移动画面。

从全站相片页进入时，底部延续当前筛选、排序和分页；照片仍逐张展平，提供所在相册／整组入口，不暗中切换为相册排序。

## 拍摄时间

读取 Immich 的 `asset.localDateTime` 与 `asset_exif.timeZone`，直接格式化当地钟表字段，不按访客或服务器时区再次转换。有效时区显示日期、时分秒与时区；缺少／无效时区显示“记录时间（时区未知）”。Immich 可能用文件时间补全日期，现有持久化字段不能完整证明 EXIF 日期来源，因此不将无时区记录冒充已核实的当地拍摄时间。

拍摄时间排序仍按现有 `fileCreatedAt` 时间值；年月筛选按 `localDateTime`。首次加入 Gallery 的排序保持原规则。GPS 修改不推算、重写或偏移拍摄钟表时间。

## 单项发布

已有效公开的相册允许保存并发布一张照片或一个照片组，包括新加入的照片。未首次发布、手动下线或任一发布祖先下线时，只可保存草稿；不得通过单项发布重新开放分支。

服务端根据目标的稳定 ID，计算草稿、当前发布版本和编辑副本中必要的组成员变更范围。在同一事务内保存该范围并生成新的不可变相册 release：保留当前公开的相册介绍、层级、排序、隐私策略及无关照片，替换目标及必要的成员关系。组内排序随组发布；已有项目的位置沿用公开版本。新项目按最近已存在的前项插入，不带出其他新选片或全册排序。

“发布相册全部修改”仍发布完整已保存草稿。局部发布后按内容比较维护 `album.has_unpublished_changes`，版本号继续用于并发保护；不再只比较草稿版本与 release 源版本来判断是否干净。源资格、媒体路径、有效发布祖先和运行时撤权检查继续适用。
