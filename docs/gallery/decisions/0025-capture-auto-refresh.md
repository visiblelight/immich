# ADR 0025：可靠 GPS 自动换算与主动重新读取

状态：2026-10-28 用户确认，先本地实现验收，随后已获生产发布授权并完成发布。补充并替代 ADR 0024 中“GPS 只产生建议”的限制；数据保护边界不变。

- 有有效 GPS UTC、原片有效位置与当前地点一致、没有无效定位标记，相机钟表可对应合法偏移且残余偏差不超过两分钟，并可确定地点历史时区时，自动换算。无 GPS 状态字段不单独判无效；无效标记、缺失 UTC、位置不符、冲突均不自动处理。保留相机秒数，不按相机型号设永久默认规则。
- 明确拍摄偏移继续优先；已有人工确认和停用决定优先于自动结果。规则升级可重新分析相同证据，但不改变证据指纹，不导致既有人工决定失效。
- 后台支持单张与明确批量选择的“重新读取”，展示等待读取、正在读取、已读取或失败。页面自动查询状态并更新；超时或失败可重试。
- 重新读取走 Gallery 独立维护队列，前后台不挂载原片、不获取 Docker 或 Immich 数据库权限。独立维护进程读取已有媒体和来源元数据，仅向 Gallery 写证据、处理状态及审计。
- 任务绑定一次请求的令牌；重复点击合并，过期任务可重试，旧任务不得覆盖新请求。来源变化时继续保守处理，最新证据读取完成后恢复核对操作。
- 不修改 Immich 原片、缩略图、sidecar 或数据库元数据，不创建重复照片，不更新 OSS，不改动相册、照片组、文章关联与人工行程日期。

实际实现与验收见 [交付记录](../delivery/capture-refresh.md)，结构见 [时间数据字典](../architecture/capture-time.md)。
