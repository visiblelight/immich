# ADR 0009：简化看图导航与沉浸查看

状态：按用户 2026-09-12 明确要求实施，视觉效果待用户查看；实际验证另记。

- 普通看图器仅在底部保留一组上一项／下一项按钮和横向缩略图，去掉画面内重复箭头与常驻键盘说明。照片组仍使用左侧垂直缩略图，移除重复的上下按钮／文字提示，保留方向键操作。
- 用「沉浸查看」替代「放大查看」。沉浸模式使用整个浏览器内容视口，完整适应照片比例，不裁切、不提供两倍放大和平移；隐藏工具栏、说明、组内缩略图和底部导航。
- 点击照片或首次按 Esc 退出沉浸、恢复普通看图器；普通模式 Esc 关闭看图器。沉浸时左右键／横向滑动继续切换项目，组内上下键／纵向滑动切换视角。切图及相片页翻页保持沉浸状态，关闭看图器后重置。
- 相册介绍使用浅色阅读面板、细边框和留白；照片说明使用区别于深色图片画布的独立底色及边界。手机端使用上下分区，保留相册介绍折叠。
- 本次不修改媒体像素输出、发布规则或数据库。替代 ADR 0005 的「放大后方向键平移」行为。
