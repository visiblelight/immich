# ADR 0021：国家内部的地区足迹地图

状态：用户于 2026-10-19 确认产品方案、第二版交互样稿样式，并授权接入真实数据、先在本地体验。本决策记录已接受的范围，样稿历史见[样稿交付记录](../delivery/china-map-prototype.md)，真实业务进度见[地区足迹交付](../delivery/regional-visited.md)。用户已于同日确认标签留白修订并授权提交、推送和生产发布。

## 导航与抽象地图

- 保留“去过”一级导航，提供“世界／中国”切换。以后可为意大利等国家配置独立地区专题，只展示已启用的专题。
- 中国地图包含 34 个省级地区：省、自治区、直辖市、特别行政区及台湾。统一使用“省级地区”作为统计单位；与世界地图的归组口径保持一致。
- 使用原创抽象几何 SVG，保持大致方位、邻接及岛屿关系。未点亮地区用浅色，已点亮地区使用站点强调色；小地区仍须具有可读标签和足够点击面积。
- [china-ex](https://lab.magiconch.com/china-ex/) 仅作为表达和交互参考，不复制其 SVG、坐标或代码。具体视觉布局需单独评审。
- 地图支持缩放、拖动和恢复全图。桌面悬浮或键盘聚焦展示摘要；触摸点选展示摘要面板，通过明确入口进入地区照片地图，拖动不应误触。
- 国家照片地图与地区足迹总览互设入口，保留已有 `/visited/CN` 及其他国家详情地址。

## 第二版样稿的视觉修订

用户在首版样稿后批准继续优化，并已确认第二版样式：

- 页面主题及入口统一使用“去过”；没有示例照片的地区统一使用“尚未留下照片”，不把缺少照片表述为确定未到访。
- 国家与省份搜索共用现有相册搜索基线组件，保持尺寸、边框、图标、输入与清除交互一致。
- “世界／中国”切换复用相册／相片排序组件的浅绿底、白色选中项样式，不另做独立视觉语言。
- 抽象地图以矩形和梯形为主，多数地区控制在 4–6 个折角，删除无意义的锯齿与细碎凹凸。在维持方位、邻接及岛屿关系的前提下，提高东部地区和标签的可读性，减少西部无效留白。
- 第二版样稿继续保留本地示例数据供回看；正式“去过”入口接入真实公开照片，生产发布独立确认，已获本轮用户授权。

## 地区识别与位置保护

- 抽象 SVG 只负责展示与点选；真实行政区边界负责照片归属；地点词典负责中文名、英文名、别名及筛选入口。三者通过稳定地区编号关联，例如 `CN-FJ`。
- 地区边界使用核验后的固定版本离线数据，来源、许可及岛屿／海岸覆盖单独记录。已选用 Natural Earth 固定版本数据，校验和、归组规则与精度限制见[数据说明](../../../packages/gallery-db/data/china-regions-README.md)。
- GPS 保持实时读取 Immich，不复制进 Gallery 发布快照。山区照片即使没有城镇匹配，也应能够独立判断省级归属。
- 公开统计沿用已发布照片资格、祖先发布链、当前版本、来源白名单、Asset 状态、媒体路径及位置公开规则；不得从未公开的 Immich 照片推导旅行信息。
- 同一来源照片出现在多个 Gallery 相册中只计一次；照片组按有效成员照片分别计数。GPS 更改、删除来源、撤回发布或资格变化在后续读取中重新核验。
- 近似位置保持当前仅公开国家级地点的边界，不用后台精确坐标额外暴露省份。后台将“受位置公开设置限制”与“归属待核对”区分。
- 国家已知、省份未知的照片仍计入全国统计，不点亮未经确认的省份；全国与各省数量差额明确提示。待核对区分“国家未识别”“省级地区待核对”“城镇待完善”，国家缺失优先处理。
- 管理员可以直接确认省级地区，不必先选择城市。人工归属绑定确认时的 GPS；坐标改变后重新核验，与自动省界结果冲突时提示处理。
- 地区地图与相片页地点筛选共用归属规则，避免同一“福建”入口得到不同范围。

## 照片地图与到访记录

- 省级详情复用真实照片地图、聚合、同坐标选片、大图、标签／相册跳转、全屏、底图、地名及返回位置恢复。
- 照片范围默认为“当前省份”，可扩展到“全国／所有国家”；扩大范围时暂停省级到访过滤，避免隐含限制。
- 省级到访独立于国家到访计算与保存。例如“福建 → 江西 → 福建”可以形成不同的省级记录，而国家仍为同一段到访。
- 到访日期仅表示照片证据，不声称精确入省、离省时间。日期不明但省份可靠的合资格照片可以点亮地区。
- 后台支持省级记录的合并、拆分、命名及日期修正，国家人工记录与省级人工记录互不覆盖；失效证据继续按现有规则重新核验。
- 后续真实实现若新增 Gallery 数据结构，迁移与完整数据字典须同批更新，保留已有国家记录，不修改 Immich 表或媒体。

## 可扩展结构

地区专题描述所属国家、展示层级、稳定地区清单、真实边界／地点映射和抽象版式。中国采用省级地区，其他国家的层级在开通时明确。数据资格、统计、交互和后台整理可复用；每个国家的抽象地图版式仍需单独设计、验收。

## 分阶段交付边界

先制作 `/design/visited/china` 本地交互样稿，受现有 `GALLERY_DESIGN_PREVIEW` 门禁保护；使用明确标注的虚构点亮状态、照片数量和到访摘要。详情演示通过 `?region=CN-FJ` 等地区编号进入。

样稿阶段不接真实地区归属。用户确认样式后已进入真实数据与完整业务实施阶段：允许新增 Gallery 结构并在备份、隔离验证后应用到本地；不修改 Immich 照片或元数据。用户随后确认本地效果并授权生产发布，按备份、专用迁移和 CI 发布流程执行。本决策补充 ADR 0006 的世界地图能力，其现有权限和国家详情行为继续适用。

## 2026-10-19 后台到访总览修订

用户确认先在本地实现：国家和省级到访各自默认展示所有地点的记录表格，每行一段到访；国家／省份由必选前置步骤改为可选筛选。列包括地点、名称、日期、照片数量、整理方式／状态与操作，按最近到访日期倒序；支持名称和地点搜索、状态筛选及分页，日期未知排后。

总览只返回摘要，打开编辑或查看照片时才加载该地点的有效照片。合并只允许同一国家或同一省份，国家与省级记录继续分别保存；部分失效记录标记待核对，完全失效的人工校正保留单独状态和清理入口，不展示已失效证据的日期、名称或照片。切换组件继续使用全站共用样式，修正长标签内边距。此轮不新增数据库迁移，不改变现有人工整理内容。实际交付见[地点选择与到访总览](../delivery/visits-overview.md)。
