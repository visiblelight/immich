# ADR 0023：前台用户、评论与点赞

状态：2026-10-24 方案及本地前后台最终效果已获用户确认，已授权提交、推送及生产发布。实际进度见 `../delivery/community.md`。

## 已确认范围

- 浏览无需登录；前台用户通过展示名称、唯一邮箱和邮箱验证码注册，登录仅使用邮箱验证码。名称无需唯一；不开放头像上传。
- 使用本站生成的低饱和几何头像，随机种子与样式版本稳定保存，生成结果防重；支持预览后更换。
- 180 天滑动续期会话；主动退出、停用、邮箱变更时撤销相应会话。前后台会话与权限隔离，注册只产生 member，不关联 Immich 用户。
- 个人资料可修改名称、换头像；换邮箱需验证旧、新邮箱并检查唯一性。不会仅凭长期会话更换登录凭据。
- 相册、统一照片、文章分别关联评论及点赞，不依赖说明是否为空，不绑定发布版本。相同照片跨相册共用互动；照片组操作针对当前照片；相册点赞不累加成员点赞。
- 每用户每内容最多一个点赞，可取消。内容当前不可公开访问时，互动也不可公开读写，不能因知道 ID 绕过资源权限。
- 评论为 1–1000 字纯文字，支持换行；不解析 HTML/Markdown，不提供表情或附件。用户可删除自己的留言；后台审核、隐藏/恢复及站长单层回复，不做多层讨论。
- 新用户首条评论审核，审核通过之前该用户其他评论也待审核；后续普通留言直接公开。作者标识由系统赋予，不能通过重名冒充。
- 后台用户管理支持停用、恢复及撤销会话；评论管理显示所属内容与审核状态。
- 独立开关：允许注册、允许新评论、允许点赞、展示评论、展示点赞。隐藏某类互动同时阻止新增；暂关保留历史数据，注册关闭不阻止已有用户登录。

## 用户本轮修订

- 暂不实施前一版方案第 7 点的专项防机器人系统：不接人机验证、不增加风险评分、IP/设备规则、评论频率限额或全站邮件额度面板。
- 保留验证码本身的有效期、一次性使用、5 次尝试上限及 60 秒重发间隔；这是登录校验语义。常规权限、Origin 校验和纯文本转义保留。
- 发信域名使用用户已配置的 `ke.ink`，发信地址 `vision@ke.ink`；发信显示名称采用站点名称“光与远方”。使用阿里云 DirectMail 触发邮件，不另建发信子域。

## 实施与回退边界

本地样稿已交付。用户随后明确：样式尚不满意，但先接入真实账号、邮件及数据库，功能闭环后再优化样式；不以视觉评审阻塞功能实现。样稿与真实业务隔离，新增能力只属于 Gallery，不写 Immich 表或媒体。

正式接入采用增量迁移与专用受限互动权限；现有公开内容读取账号保持只读，运行服务不使用迁移或管理员数据库凭据。公共内容与个性化状态分开缓存；邮箱、验证码、会话不进入公开响应。

生产发布另行验收，功能初始关闭；可关开关并回退兼容应用，保留新增互动数据。

## 2026-10-24 前台交互修订（用户已确认，本地实施后再验收）

- 未注册邮箱获取登录验证码时明确提示尚未注册；允许注册时可带着邮箱转去注册，关闭注册时不提供注册入口。不发送假验证码、不启动误导性倒计时。停用账号显示不可登录原因。
- 文章评论跟随正文列左右边界，始终展示；评论按创建时间从早到晚排列，输入入口在列表下方，点击才展开。
- 相册点赞移到标题旁，保留心形图标及非零数量。说明和评论共用右侧阅读区；无说明但有评论仍显示评论，无说明也无评论时隐藏整栏，在照片工具行保留写评论入口。手机使用底部面板。
- 照片点赞浮在画面上，不依赖信息栏开关。右栏使用与站点一致的分段控件切换照片信息／评论，拍摄信息和评论分开显示。桌面评论输入固定在侧栏底部。
- 评论使用轻量头像、名称、时间与正文；发表表单默认收起，取消或切换标签保留当前页面草稿，提交失败不清空。长列表分页追加，新提交的本人评论可立即看到；待审核状态仍只对本人展示。
- 登录、注册及个人资料延续前台的留白、低饱和配色、细线输入和轻量按钮。资料默认阅读，修改名称和随机头像时才展开表单。保留原有邮箱验证与权限边界，不新增社交能力。
- 本轮仅本地修改与验收，不提交、推送或发布生产；用户确认视觉后再发布。

### 2026-10-24 视觉验收补充

- 相册有说明、尚无评论时不显示空评论提示文字和“评论 0”标题，只保留收起的发表入口；有评论时恢复标题与数量。
- 文章暂时隐藏点赞入口及数量，保留既有点赞数据和服务能力，方便将来恢复。文章评论继续常显。
- 照片标题、说明和标签放到评论页上方；照片信息页保留拍摄时间、地点、EXIF 及所在相册。关闭评论展示时，已有作品说明仍可通过“说明”标签阅读。

### 2026-10-24 后台使用反馈

- 互动设置去掉“暂停新增互动”快捷按钮，保留各项独立开关和保存设置。
- 评论管理直接在留言旁展示所属类型、内容名称及前台链接；照片优先打开当前公开相册中的对应大图。仅出现在文章中的照片链接到所在文章；内容已不在公开视图中时明确标注未公开，不生成无效入口。
- 用户搜索框和按钮保持同高、按钮文字不换行；用户管理表格的各列内容垂直居中。

### 2026-10-24 列表点赞展示调整

- 相册卡片的点赞统计与“共 xx 张照片”放在同一行，靠右对齐；子相册卡片遵循相同布局。
- 相册和相片列表的点赞数为零时，隐藏整组爱心与数量，不留下单独空行。尚未加载和关闭展示时也不显示计数。
- 详情里的点赞按钮继续保留，方便用户点出第一个赞；零值数字原本已隐藏。
