# ADR 0014：统一前台外框、站点配置与照片工具

状态：2026-09-15 用户确认九项优化，授权实施；实际验证见交付记录。

- 五个一级页面统一页头、外层宽度、响应式边距和居中页脚；文章正文独立控制阅读宽度。
- 记录封面缩为约 160×106px，不撑高短文章条目；无标题照片不显示占位标题。
- 站点设置统一保存名称、简介、联系链接、关于选篇、版权署名和页脚短句；注明显示位置。联系链接不再依赖旧版关于页面。
- 看图器占满视口，右上角统一图标：信息、全屏欣赏、复制当前照片页面链接、关闭；照片组按需提供视角开关。保留照片完整比例、组内上下和项目左右导航。
- 全屏欣赏优先浏览器全屏，不支持时使用视口沉浸。退出与焦点恢复保持一致；不新增放大和下载原片。
- 点击控件不保留强烈焦点框，键盘焦点保持细微可见。筛选选中态使用轻底色，统一标签尺寸与帮助文字间距。
- favicon 使用原创矢量取景框、光点和地平线，墨绿与暖白；提供常用兼容格式，实际视觉待用户体验。
- 仅增加 Gallery 站点字段，不修改 Immich 表与媒体，不改变照片发布及访问权限。
