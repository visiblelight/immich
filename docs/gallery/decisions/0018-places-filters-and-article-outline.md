# ADR 0018：规范地点、组合筛选与文章目录

状态：用户于 2026-10-05 确认；实际交付见 [交付记录](../delivery/places-and-outline.md)。

## 已确认范围

- 前台目录独立滚动，桌面加宽；后台富文本编辑器显示 H2/H3/H4 目录，点击定位光标，修改标题同步更新目录。
- 照片详情显示可点击的国家、一级行政区、城镇名称。点击某层进入 `/photos` 筛选该地点及下级照片。此阶段不承诺街道、建筑和景点级识别。
- Gallery 维护轻量地点词典：中文、英文、别名、重复地点合并、照片归属校正。Immich 继续作为 GPS 唯一来源。
- 相片页左侧加入地点、自动聚合的相机/镜头、实际焦距筛选。焦距包含范围两端，不混用 35mm 等效焦距。
- 停用标签立即退出公开展示与筛选，保留草稿和发布关联，启用恢复。此规则取代 ADR 0010 的“停用仍保留公开引用”。
- 相册统计改为“共N张照片”。

## 地点判断与隐私

国家沿用地图的离线边界与归属规则。城镇使用 GeoNames 稳定编号，名称与编号分离；更名不破坏已分享 URL。自动判断必须同时获得来源名称与附近坐标印证，不能只按最近城镇自动归属；无法确认时降级到国家，由管理员校正。

内置城市和一级行政区数据包含中文/英文别名，缺少中文时显示英文或原可读名称。浏览时不发送照片坐标给外部服务，不使用公共 Nominatim 批量查询。

隐藏位置不展示地名；近似位置最多展示国家，不经城市筛选泄露精确位置。隐藏 EXIF 时不进入设备或焦距筛选。跨相册重复照片取较保守的隐私策略并按 Asset 去重。

人工归属记录当时坐标作为失效校验，GPS 改动即失效；不把 GPS 写入发布快照。地点修改是全站统一生效的元数据校正，不重写相册、照片、文章发布版本。

## 筛选语义

不同维度取交集，同一相机/镜头维度多选取并集；现有多标签仍取交集。焦距缺失的照片在有范围时排除，未限制时保留。型号只规范大小写、空白和 Unicode，不擅自合并不同商品型号。

筛选状态存于 URL；分页、年月、排序保留条件。设备和地点候选按其它条件聚合，只使用合资格公开照片，不查询私有图库产生公开候选。

## 筛选视觉修订（用户反馈后确认）

四项筛选不采用折叠面板：字段名与当前选择常驻侧栏，点击控件才展示候选弹层。地点单选直接应用；相机、镜头多选和实际焦距通过弹层内“完成”应用。关闭或Escape不应用未确认选择。手机使用底部弹层，候选列表不占正文空间。数据署名保留于地点选择弹层。

2026-10-05 后续反馈：地点弹层使用国家、省州、城镇的嵌套列表，不再平铺；选中上级包含下属区域，搜索保留父级上下文。照片详情用轻量的 `国家 › 省州 › 城镇` 分隔明确表达层级，保持可点击筛选，不恢复下划线或独立箭头按钮。此要求替代先前仅用留白区分地名的方案。

2026-10-06 编辑界面反馈：后台目录作为可隐藏的辅助导航，默认收起，字号与前台目录保持一致；优先保证正文编辑空间。长文滚动时，保存/预览/发布操作栏和文字格式栏保持可用，右侧文章设置独立滚动。地点照片归属列表使用独立布局，不能继承相册照片网格而挤压文字与控件。
