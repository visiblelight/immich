# ADR 0028：仅地点变化时复用相机时区确认

状态：2026-11-01 用户确认本地实现，完成本地验收后授权提交、推送及生产发布。补充 ADR 0024–0027。

- 对明确人工确认过相机时区的照片，重新采集证明源拍摄时间、相机钟表及源时间证据未变，仅地点相关信息变化时复用相机时区，按最新可靠位置重新计算当地时间。没有地点时保留相机钟表，不沿用旧地点时区。
- 原始时间字段、EXIF 钟表/偏移/日期来源或 GPS 时间证据变化，或新生效 GPS 证据与确认冲突时，不复用。停用决定不自动恢复。沿用现有版本、请求代次、来源签名与发布资格保护，不建立型号默认时区。
- 独立保存不含位置的源时间签名。旧记录仅在当前来源仍匹配旧证据时补齐基线，无法证明的历史过期记录不猜测。更新 Gallery 校正版本并审计复用，保留原确认人。
- 后台到访表格优先按国家/省份名称排列，同地点按日期倒序。自动到访随当前证据重算；人工到访保留明确选片，后来的照片不擅自并入，可用既有合并操作整理。
- 拍摄时间列表为仅文章可见照片补充前台文章照片直达链接；无公开入口时提供后台核验入口并说明，不通过链接授予公开资格。
- 不写 Immich 表、原片、sidecar、缩略图或 OSS，不改变相册、照片组、文章关联与人工行程成员。
