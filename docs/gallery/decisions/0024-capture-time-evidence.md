# ADR 0024：独立拍摄时间校正

状态：2026-10-26 用户确认，先本地实现和验收；生产发布另行授权。替代 ADR 0005 中“有效时区即可标为当地时间”的判断。实际进度见 delivery/capture-time.md。

- 区分相机钟表、拍摄时间的显式时区、位置对应的历史时区。规则与品牌型号无关。
- 显式拍摄偏移确定真实时刻；位置决定当地显示。GPS UTC 仅作为交叉核验与建议依据，存在 GPS 字段不代表定位有效。缺失、无效、陈旧或冲突的证据不自动校正。
- 相机时间与 GPS UTC 接近一个合法偏移仅产生建议，保留相机秒数。人工确认可按明确选择的照片批量应用；不创建永久相机型号默认规则。
- Gallery 保存只读采集证据与独立确认记录，绑定来源时间、位置及证据指纹。来源变化后旧确认失效，重新核对；撤销可恢复 Immich 原记录。
- 原片、缩略图、OSS、Immich 表和 sidecar 均不写入，不创建重复照片。Gallery 相册、照片组、文章引用、公开快照、人工到访记录不改写。
- 展示、排序、年月筛选、自动到访推断共用有效时间。未确认的时间明确标注，不能作为已确认的当地到访日期。人工行程显式日期保留。
- 采集在独立维护进程中执行，只读访问现有 Immich 媒体；前后台不新增原片挂载，不接收数据库所有者凭据。采集失败保留旧证据，不以空记录覆盖。
- 后台提供待核对/已确认/全部列表、原时间与建议时间、原因、明确批量选择、预览影响和撤销。使用已有后台组件风格。第一版不增加自动机器型号推断。
