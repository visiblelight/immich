# ADR 0012：记录、富文本文章与关于选篇

状态：产品方案已确认，2026-09-14 用户授权实施。页面视觉与写作体验须单独评审；实现情况见交付记录。

## 已确认的范围

- 一级导航顺序：相册、相片、去过、记录、关于。文章独立于相册，可写正式游记、纯文字或其它主题；相册及照片 Markdown 不迁移。
- `/records` 按发表时间倒序，封面可选；`/records/[slug]` 提供长文阅读、标题目录、正文图片沉浸浏览。标题紧凑，不使用装饰英文或巨大首屏。
- 后台新增文章列表及独立编辑页，提供 Tiptap 富文本、自动保存草稿、预览、显式发布／更新和下线。正文结构化存储，不接受任意 HTML。
- 首期格式：段落、H2/H3、加粗、斜体、列表、引用、链接、分隔线、图片及说明、撤销重做。字体与排版统一控制。
- 图片可引用已公开 Gallery 照片，或者额外上传文章素材。文章中的图注是上下文，不修改全站共用照片资料。
- 额外素材归 Gallery 管理，不自动进入 Immich、相册、相片流或去过统计。摄影照片继续引用 Immich 展示图，不重新缩放。
- 文章可关联多个相册，相册也可关联多篇文章；不绑定来源 Immich 相册。
- 关于页面选择一篇已发布文章，共用其当前发布版本。文章可不列入记录列表，但“未列入”不是私密。正在使用的关于文章需先解除／更换关联再下线或删除。

## 发布与图片边界

- 草稿、预览、公开版本明确分开。文章发布不发布照片草稿，也不发布相册。
- 图片节点只存资源引用、类型及正文图注，不接受任意远程 URL、文件路径或 HTML。服务端验证结构并解析图片授权。
- 引用 Gallery 照片时，记录明确的来源 Gallery 相册上下文；公开请求仍检查该相册祖先、当前发布成员、来源范围、资源状态和实际媒体路径。来源不再公开时展示缺图状态，不改用另一相册绕过限制。
- 独立素材必须属于当前公开文章版本（含封面）才可公开读取。仅知道素材 ID 不构成权限；草稿素材仅允许认证后台读取。
- 首期匿名媒体响应沿用现有缓存撤回边界，不宣称能收回访客此前下载的图片。新增存储须有备份恢复及未引用素材清理规则。

## 实施阶段

1. 文档、结构化内容基础与可操作的前后台样例；评审视觉和写作体验。
2. 新迁移及隔离验证、文章草稿与发布、素材上传与授权、关于选篇与关联相册。
3. 备份后应用开发库迁移、真实闭环与移动端验收。
