# ADR 0017：全站照片管理与浏览细节

状态：按用户 2026-09-27 的十项要求实施；实际验收见交付记录。

- 纯父相册也能选封面：可从本册或草稿树中的任意后代相册选择非文章专属照片，不要求先发布子相册。公开封面仍只允许来自当前有效公开后代；不会因为选封面而公开草稿照片。
- 相册介绍为空时不留空卡片，并释放右栏宽度。照片文字为空时隐藏文字块，仍保留存在的拍摄时间、位置和 EXIF；参数名称／数值统一左右对齐。
- 世界足迹已去过国家改为暖金色，未去过国家维持空白且无操作。
- 相册照片去掉灰色底板，组图增强错位叠层；文章组图保留图片内箭头，常态即可发现，不重新加入组名、数量和底部控制栏。
- Immich 选片弹窗左右独立滚动；切换来源或翻页后右侧返回顶部，左侧仍可切换相册。
- 后台新增“全部相片”：按 Immich asset 去重，显示所属 Gallery 相册；支持检索、相册／标签／展示状态筛选、分页、多选和单独编辑。
- 标题、Markdown 描述、标签仍是一份共享资料，跨相册更新；照片组使用其组说明。本次不改变组说明或成员关系。
- 每批最多 100 张。标题／描述可保留、替换、清空，标签可保留、追加、移除、替换、清空。批次默认保留所有字段。提供保存草稿与保存并发布资料；任何版本冲突或发布校验失败均回滚整批。
- 发布照片资料不会发布相册草稿结构或文章；公开访问继续受已发布相册／文章引用和实时来源资格约束。
- 所有公开页面统一使用 strict-origin-when-cross-origin，解决客户端页面切换后缺少 Referer 的地图请求。跨站只发送站点来源，不发送页面路径或查询参数。
- OSM 标准栅格图保持可选，其文字已经画在图片中，不能切换语言。增加官方矢量底图预设，英文优先并在没有英文译名时回退当地名字；不承诺全中文。Google SDK 请求中文界面／标签。OSM 官方服务没有 SLA，不增加代理绕过或批量抓取。

本次无数据库结构迁移，Immich 表和媒体不变。实际地图服务说明见 [OSM 瓦片政策](https://operations.osmfoundation.org/policies/tiles/) 与 [矢量服务政策](https://operations.osmfoundation.org/policies/vector/)。
