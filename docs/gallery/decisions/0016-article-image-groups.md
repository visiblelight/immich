# ADR 0016：文章图片、隐藏作品与图片组

状态：用户已确认并授权实施；实际验证单独记录。

- 三种图片：公开 Gallery 作品、从图库隐藏但可被文章引用的 Gallery 作品、独立上传的文章素材。前两种都只能来源于 Immich，保留相册归属与全站共用资料；第三种不进入作品库。
- `hiddenFromGallery` 是照片共用属性，与标题一起保存草稿和显式发布。发布后排除相册、相片、地图、公开标签及封面。后台仍可选片、管理及写作引用。
- 文章图片访问要求当前文章发布引用、来源相册及祖先已发布、当前相册版本仍包含照片、来源范围和资源状态有效。隐藏属性只取消图库浏览，不自动授权任何公开图片；草稿、历史引用和猜测 ID 均不能授权。
- 直接插入 Gallery 照片组保留组引用，跟随来源组的当前发布成员；保存来源草稿不影响文章。来源组删除或下线时展示不可用，不绕过来源限制。
- 文章临时组可混选 Gallery 照片和上传素材，有独立顺序及上下文图注，只随文章发布，不创建相册照片组。最多每组 50 张、整篇 200 张（发布时计入引用组成员）。
- 前台图片内浮动左右按钮、滑动、组内沉浸查看；不自动播放、不裁切画面。文章上下文图注不修改作品共用描述。
- OSS/CDN 沿用已确认的 5 分钟签名撤销边界；仅同步当前公开引用授权的展示图，不上传原片。

## 文章视觉修订（2026-09-21，用户明确要求）

单图与图片组按普通图文博客统一展示，不设背景卡片、不显示组名、数量或底部提示栏。箭头叠在图片两侧，鼠标悬浮或键盘聚焦时淡入，触屏保留轻量箭头和滑动。组图按首张图片比例保持稳定区域，完整展示不裁切。只显示作者在文章里填写的图注，禁止自动带入来源组标题、Markdown 描述及其分隔线。编辑器沿用正常图片排版，只在图片角落提供编辑入口。
