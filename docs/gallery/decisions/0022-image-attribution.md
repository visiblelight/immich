# ADR 0022：Gallery 输出照片的创作者署名

状态：2026-10-21 用户确认，先本地实现、验收后另行授权生产发布。

- 默认创作者与创作者主页均由用户指定为 `https://vision.ke`，可选版权说明留空。通过 Gallery 站点设置独立启用、修改或关闭。
- Immich 原片、Thumbnail、Preview 均只读；不修改 Immich 表、路径和文件，不创建新的照片记录，不改变 Gallery 相册、照片组、文章引用、发布版本和排序。
- 从 Immich 取得的图片在 Gallery 输出阶段先清除隐私元数据，再写入配置允许的 EXIF Artist / Copyright 和 XMP Creator / CreatorContactInfo.CiUrlWork / Rights。EXIF ASCII 无法表达的中文保存在 XMP，不乱码转写。仅改容器，压缩图像数据、尺寸、ICC 与透明度不变。
- 生效范围包含相册、封面、照片组、文章引用照片及后台来源预览。独立上传的文章素材可能属于第三方，不自动套用个人作者；其关联与处理规则保持原状。
- 本地采用有容量上限的内存处理缓存，不落一整套署名图片库。缓存标识包含确定性的署名配置；关闭恢复无署名输出。同一来源与配置产生相同内容哈希，不加入时间戳、随机编号或配置修订号。
- 仅 Gallery 已公开使用的照片同步到 OSS；未发布照片不会因为启用署名变成公开内容。新旧图片通过内容哈希分址，未同步成功时从授权源站返回新版图片，不回退旧 CDN 内容。原有发布授权和撤销时限保持。
- 同步任务提供聚合进度与失败重试状态；生产首次更新前暂停旧对象回收，验收完成后恢复。原片与关联不动，旧应用兼容新增独立配置表。关闭功能或回滚应用均无需重选照片、重建相册或重新发布；已被访客下载的文件无法追回。

实际交付记录见 [图片署名](../delivery/image-attribution.md)。
