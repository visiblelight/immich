# ADR 0026：分别确认相机时区与拍摄地点时区

状态：2026-11-01 用户确认实施，并授权完成验证后发布生产。补充 ADR 0024/0025，可靠 GPS 的自动判断条件保持不变。

- EXIF 相机钟表已存在但 GPS 无效时，管理员可以分别确认相机当时采用的时区和拍摄地点时区。二者都确认后换算当地时间，不要求原片 GPS 必须有效。
- 现有可信地点时区可沿用；GPS 无效时仅将 Immich 的地点时区作为明确标注的候选，必须主动选用或填写。不把候选自动当作有效定位，不修改采集证据及其指纹。
- 地点暂不确定时可以只确认相机时区：真实时刻用于排序，显示明确标注“相机时间 · UTC 偏移（拍摄地点时区待确认）”；不把相机日期用于已知日期的自动行程。
- 批量核对使用同一相机时区、各自的地点时区；可显式选用各照片候选，也可逐项填写或留空。预览分别标注当前时间、确认后的当地/相机时间以及排序时刻变化，修改输入后须重新预览。
- 校正继续保存在 Gallery 独立记录，沿用版本、来源签名和证据指纹检查，可停用恢复 Immich 原记录。原片、元数据、缩略图、OSS、内容关联和人工行程不写入。
