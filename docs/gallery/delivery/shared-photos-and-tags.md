# 统一照片资料与标签交付

日期：2026-09-12。依据 [ADR 0010](../decisions/0010-shared-photos-and-tags.md)。

状态：代码已实现；候选构建与隔离验证通过。开发图库尚未迁移，新功能尚未切换到 3100/3101；不能将本记录视为已上线。

## 实现

- 独立 photo / photo_release 维护唯一草稿与不可变发布版本，同一 Asset 在所有相册共享资料。
- 标签统一词库，支持创建、重命名、启停、无引用删除，照片多选和快捷创建、照片组成员单独选择及全组批量添加/移除。
- 草稿保存不会改变公开资料，照片发布更新所有当前公开引用，相册结构、分组、位置和 EXIF 公开开关仍按相册约束。单项发布不带出其它相册未发布的介绍、选片或排序。
- 相片页多标签交集与年月、排序、分页联动；详情标签跳转；公众只能看到来自有效公开照片的标签及去重计数。
- 标签关联存入照片发布快照，名称统一实时解析；改名保留 ID 链接；停用阻止新增关联但保留已有内容。
- 统一照片版本与相册版本阻止旧编辑窗口覆盖，新选片读取已有照片资料。新增版本更新涉及相册的待发布状态。
- 新增 0007 迁移与 5 张 Gallery 表，保留原相册字段及历史快照，不修改 Immich。EXIF 限定白名单，GPS 不复制。

## 开发环境与迁移前确认

本次先发现并恢复了未监听 3100 的前台服务，相片页已返回 200。后台 3101 原本仍在运行。当前是终端进程，未配置自动重启；不能据此推断退出原因。

只读预检发现 12 个 Asset、13 个相册引用，其中 1 个 Asset 的两处标题/描述有“非空／空白”差异，已请求用户决定保留方式。真实标题与正文不写入此文档。等待回答期间仅操作源码及隔离验证库。

迁移前必须重新只读检查（用户可能继续编辑），得到必要确认后备份现有数据库，再暂停 Gallery 前后台并执行 0007。脚本拒绝多个不同非空资料版本；对已确认的非空/空白选择保留非空记录，草稿与当前公开资料分别回填，不将草稿误发布。两个版本分别保留，旧快照不改写。

候选构建使用 `GALLERY_BUILD_SUBDIR=shared-candidate`，产物独立于已运行的预览构建。切换前执行默认构建及重启，确认 readiness、相册、相片和媒体访问。

## 回滚边界

旧相册字段与历史版本保留用于审计，但统一照片发布不会重写其它相册历史快照，因此迁移后已有新编辑时不能只退回旧代码作为无损回滚。需要先保全新增资料，在隔离库验证迁移前备份及恢复方案后再切换；不得覆盖恢复正在使用的 Immich 数据库。当前尚未迁移，无真实资料变更。
