# Immich 展示图画质交付

日期：2026-09-12。需求见 [ADR 0008](../decisions/0008-immich-image-quality.md)。

## 已实现

前后台媒体接口沿用 Immich 的 Thumbnail／Preview 衍生图，取消 Gallery 的 600／2560 长边缩放和 WebP 二次压缩。JPEG／WebP 的压缩图像数据、像素尺寸、ICC 和透明度保持；HTTP 返回真实 MIME 类型。图片容器中的 EXIF、GPS、XMP、IPTC、注释、非显示用途附加块与尾部数据被移除。

发布授权、祖先检查、资源状态、匹配编辑变体、只读衍生目录与 no-store 保持。处理结果按文件内容缓存，重建衍生图后无需重发相册。未知格式、异常方向、动画和损坏结构拒绝输出，不回退原图。未新增依赖、迁移或 Immich 配置修改。

## 验证

- `gallery:check` 无错误／警告；前后台 `gallery:build` 通过；`gallery:smoke` 四种启动模式通过。
- `gallery:test` 31 项通过。新用例覆盖 3240×2160 JPEG（普通／渐进）及 1620×1080 WebP（有损／无损），比较压缩图像数据和解码像素、尺寸、ICC、透明度；检查附加元数据移除、来源替换、小图不放大和无效输入拒绝。
- `gallery:test:db` 23 项通过，包含生产 HTTP 媒体格式、发布／撤销、权限、缓存授权和备份恢复；上游迁移与结构检查通过，Gallery 引入的 Immich 结构差异为 0。临时容器已清理。
- 真实开发图库 18 个媒体响应逐一与 Immich 衍生文件比对：HTTP 格式／尺寸正确，像素及 ICC 一致，EXIF／XMP／IPTC 已清理；前后台就绪端点均为 200。只读取已公开图片，没有写入原图库。
- 浏览器自动化连接不可用，本次通过真实 HTTP 图片响应核对，没有声称完成浏览器视觉验收。

隔离数据库首次启动检测误认了 PostgreSQL 临时引导进程，导致导入前连接失败；测试脚本改为等待最终 TCP 监听，避免引导进程重启竞争。修复后完整回归通过；本次耗时约 10 分钟，主要耗在万张合成数据插入和恢复时的地理索引重建。

## 当前预览与来源尺寸

相片页：http://127.0.0.1:3100/photos；后台：http://localhost:3101/albums。

核对时现有衍生文件仍是旧尺寸：缩略图 333×250／375×250；预览图 1918×1440、2048×1365、2160×1440。因此本次代码已解除 Gallery 限制，但尚不能把真实图库称为 1080p／4K 图片验收。用户在 Immich 完成「任务队列 → 生成缩略图 → 全部」后，刷新 Gallery 即使用新文件；原片较小则仍保持较小尺寸。
