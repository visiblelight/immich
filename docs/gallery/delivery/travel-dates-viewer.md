# 旅行日期与移动端看图器修复

状态：2026-10-24 已发布生产并完成真实图库验收。

## 本轮需求与实现

- 世界及中国省份地图的“沿途的记忆”保留地区名称、记录数、照片数，下方逐段列出旅行日期。同一天只显示一个日期，多次旅行分别显示，不合并成连续区间。
- 地区按该地区所有公开照片中的最早当地拍摄日期倒序排列；地区内行程同样按各段最早拍摄日期倒序排列。缺失日期放最后，同日期按 ID 保持稳定顺序。
- 到访概要新增只读 `photoStart`，从现有公开照片证据计算。手动修正的旅行日期继续用于显示，不会覆盖照片拍摄时间排序依据。地图弹层及详情页筛选同时保留行程标签与日期。
- 手机看图器打开信息时，图片区与信息区使用明确的两行布局，共用滚动区域。图片完整等比显示在限定高度内，信息跟在图片之后；照片组缩略图仅占图片所在行。桌面、隐藏信息与沉浸模式保留原有布局。
- 增加 `/design/viewer` 示例页，复用实际 Gallery 看图器和已有示例素材，便于在无数据库时检查横竖图、组内切换和信息栏。仅在 `GALLERY_DESIGN_PREVIEW=1` 下开放，与现有设计页采用相同门禁。
