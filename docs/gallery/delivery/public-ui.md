# 公共界面与站点设置交付

日期：2026-09-15。对应已确认 ADR 0014。

## 实施

- PublicFrame 统一相册、相片、去过、记录、关于和文章详情的外框、导航及居中页脚，相关文章位于页脚之前。
- 记录封面改为 160×约106px，响应式保持较小封面；照片列表不显示自动占位标题，保留无障碍名称。
- 站点简介用于页面摘要及默认关于介绍；联系链接显示于全站页脚。版权署名默认站点名称，页脚短句可选。关于选篇与其它配置同一次提交，校验并发和文章发布状态后原子保存。
- 看图器占满视口，统一信息、全屏、复制页面链接及关闭图标；保留照片组双向导航、完整画面和文字阅读内边距。浏览器全屏不可用时回退视口沉浸。
- 标签筛选统一字号、内边距、轻底色和帮助文本间距；鼠标不保留焦点描边，键盘仍提供细轮廓。
- 原创取景框、光点、山形地平线 favicon；SVG、16/32px ICO、32px PNG、180px触屏图标同时接入前后台。

## 数据与兼容

0010_site_presentation 仅扩展 Gallery site 和公开站点视图；不修改 Immich 表、照片文件、已发布内容或权限规则。旧应用可忽略新列；建议回滚应用并保留增量字段。生产部署仍需先执行迁移再启动新版本。
