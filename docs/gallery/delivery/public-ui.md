# 公共界面与站点设置交付

日期：2026-09-15。对应已确认 ADR 0014。

## 实施

- PublicFrame 统一相册、相片、去过、记录、关于和文章详情的外框、导航及居中页脚，相关文章位于页脚之前。
- 记录封面改为 160×约106px，响应式保持较小封面；照片列表不显示自动占位标题，保留无障碍名称。
- 站点简介用于页面摘要及默认关于介绍；联系链接显示于全站页脚。版权署名默认站点名称，页脚短句可选。关于选篇与其它配置同一次提交，校验并发和文章发布状态后原子保存。
- 看图器占满视口，统一信息、全屏、复制页面链接及关闭图标；保留照片组双向导航、完整画面和文字阅读内边距。浏览器全屏不可用时回退视口沉浸。
- 标签筛选统一字号、内边距、轻底色和帮助文本间距；鼠标不保留焦点描边，键盘仍提供细轮廓。
- 原创取景框、光点、山形地平线 favicon；SVG、16/32px ICO、32px PNG、180px触屏图标同时接入前后台。

## 2026-09-16：全屏看图叠层修复

- 用户反馈并复现：点击全屏后，导航和列表叠在大图上。之前仅检查按钮可见性与切图状态，未充分检查全屏截图，漏检了实际绘制问题。
- 原因：根文档进入浏览器全屏后，在浏览器顶层中的绘制顺序晚于已经打开的 modal dialog。共享全屏逻辑在成功后重新提升当前看图弹窗，屏蔽此次重排产生的临时 close 事件，保留选片、路由及焦点。仍以根文档作为全屏目标，以支持切图时组件重建。
- 照片与文章图片统一标记看图弹窗；看图期间取消滚动条预留宽度，消除右侧白边，关闭后恢复正常页面的稳定宽度。全屏申请期间退出会撤销迟到的全屏，浏览器拒绝时仍回退视口沉浸。
- `gallery:check`（0 错误、0 警告）、`gallery:build`、`gallery:smoke` 通过。Chromium 在 1440×1000、390×844 下验证照片、照片组、文章插图、跨照片路由切换、反复进入、点击退出、浏览器退出以及拒绝全屏后的 Esc 恢复，无页面脚本错误。
- 12 个截图场景检查：对比正常全屏截图与隐藏弹窗之外背景内容后的截图，像素完全一致；同时断言看图弹窗覆盖整个视口宽度，并人工检查桌面／窄屏截图。证据与本地复验脚本保存在 `.gallery-local/verification/public-ui/`。窄屏为 Chromium 模拟，未代替 Safari 或手机真机验收。
- 已重新启动本地 3100／3101 服务。此修复不涉及数据库迁移；回滚只需恢复应用版本。
