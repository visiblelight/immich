# 文章隐藏作品与图片组交付

日期：2026-09-21。已实现并接入本地环境，用户已完成本地验收并授权推送上线；生产发布结果将在执行后追加。产品规则见 [ADR 0016](../decisions/0016-article-image-groups.md)，数据字典见 [文章结构](../architecture/articles.md)。

## 使用入口

- 后台相册 → 编辑照片 → “仅在文章引用时展示”。照片组编辑可批量设置全组，也可逐个成员设置。保存是草稿；发布后在所有相册共享生效，仍保留后台成员关系。
- 后台文章 → 图片 → Gallery 照片 / Gallery 照片组 / 上传素材。Gallery 选项包含来源相册已发布的隐藏作品；来源相册未发布时先在相册完成发布，隐藏作品不会因此出现在图库。
- 单张可逐张插入；跨相册及素材类型多选后“组成图片组”，拖动或箭头调整顺序，填写文章独立说明。重新编辑可增减与排序，至少两张。
- Gallery 照片组直接引用已有组，成员跟随来源组的发布更新；文章可以填写独立图注。临时组只跟随文章发布。
- 前台提供完整画面轮播、图片内浮动左右按钮、原生横向滚动/滑动和当前组内沉浸大图；无自动播放。文章素材继续不进入作品库。

## 权限与 CDN

新增 0011 迁移（仅 Gallery schema）。图库公开视图排除隐藏作品；文章专用媒体地址每次检查当前文章引用和来源相册、祖先、成员、来源资源及路径。移除引用、下线文章、来源组删除或来源相册下线会撤销对应授权。

CDN exporter 已纳入当前文章授权的 Gallery 展示图，内容寻址去重，图片仍使用 Immich 两种衍生图；没有新增原片访问。继续遵守已确认的旧签名最长 300 秒撤销边界。

## 文章图片视觉修订

已按用户反馈统一单图与组图的正文排版：移除背景卡片、组名、数量和底部控制行，使用图片内悬浮箭头；手机保留轻量箭头和原生滑动。组图依据首张图片比例稳定布局，完整显示所有照片。只渲染文章明确填写的图注，不再自动带入来源组 Markdown（含标题、分隔线）。编辑器取消大块信息按钮，改为图片角落的编辑入口。

本轮 `gallery:check`（0 错误、0 警告）、`gallery:test`（45 项）、`gallery:build` 通过；新增回归验证来源描述不会生成标题/分隔线、显式图注仍安全输出。已在本地独立预览检查桌面和 390px 布局、箭头及键盘切换、编辑器图像和编辑弹窗；无横向页面溢出。触屏手势仍待真机验证。已重启本地前后台，未修改用户文章内容，未发布生产。

## 后续生产上线步骤

生产尚未应用 0011。沿现有发布流程备份、用专用迁移角色应用 0011，然后发布对应代码镜像并验证 ready 与 CDN exporter。CI 对迁移历史有严格检查，不能只推新代码而忽略协调迁移。旧编辑器不认识新增图片组节点，回退前需禁止旧编辑器保存含新节点的文章；不要删除新增引用表或覆盖用户新内容。
