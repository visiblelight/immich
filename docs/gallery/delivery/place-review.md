# 地点核对与沿海照片归属

2026-10-17：根据 ADR 0018 后续确认实施，经用户授权已发布生产。生产罗卡角照片仍待管理员人工确认，不改动 Immich GPS。

## 实现

- 默认待核对列表与计数使用同一 `needsReview` 口径；全部切换仅展示已有 GPS 的图库照片。支持文件名/来源地点搜索，明确国家缺失、城镇未匹配、自动匹配、人工确认等原因。
- 人工确认到国家或省州也算核对完成。过期 GPS 指纹不再视作有效人工确认；有效自动判断仍可正常使用。
- 严格边界外 1km 内、5km 内没有其它国家外边界时提出沿海候选；不改动原边界数据，不自动归国。罗卡角坐标可得到葡萄牙候选，来源 Azoia/Lisbon 与附近城镇交叉吻合，优先显示完整路径。
- 原卡片内搜索其它地点、按需展开坐标地图；地图使用本站固定版本 MapLibre、已有本地样式及失败降级，坐标经 URL fragment 传入，预览路由不查询照片。地图不展开时不加载地图服务，不自动发送坐标给地理编码接口。
- 同坐标批量选择与确认，服务端限制 100 张，逐张检查授权、GPS、版本，同事务全成全败并逐张审计。恢复自动判断入口保留。
- 前台详情/筛选与去过共享有效人工归属，无需重发相册。隐藏、近似、跨册保守策略仍有效。

## 验证

Gallery 单元测试通过；隔离 PostgreSQL 26 项回归通过，Immich schema drift 为零。新断言覆盖沿海候选距离、两国歧义、同坐标批量确认、版本冲突整批回滚、异国校正拒绝、确认后国家/城镇筛选和去过同步、GPS 变化后两侧同时撤销、仅确认国家退出待核对。

本地后台验证待核对空态、全部 11 张、文件名过滤及同坐标 6 张选择；未保存真实本地照片的归属。构建、最终地图和窄屏验证见后续记录。

## 兼容与回滚

无数据库迁移、无依赖升级。仅添加基于既有 `photo_place` 的应用行为。回滚旧应用后，原先国家识别失败的沿海人工记录不再被旧逻辑采用，但不影响记录保留。用户已有 mise.lock 修改未纳入本轮变更。
