# 沉浸看图与说明分区交付

日期：2026-09-12。需求依据：[ADR 0009](../decisions/0009-immersive-viewer.md)。实现与本地验证完成，视觉效果待用户查看。

## 已实现

- 普通看图器只保留底部一组左右按钮，去掉图片浮动箭头和重复的常驻键盘提示；照片组保留左侧缩略图选择。
- 「沉浸查看」替换「放大查看」，隐藏工具栏、说明和两层缩略图。照片按比例完整适应浏览器内容视口，不裁切、不二次缩放生成图片；隐藏背景页面滚动条。
- 点击画面或按 Esc 恢复普通模式，再按 Esc 关闭。方向键继续切换相册项目／组内视角，路由切图时保持沉浸状态，关闭后重置。触屏实现横向切项目、沉浸时纵向切组内视角，滑动后不会同时触发点击退出。
- 相册介绍增加浅色面板、标题、边界和留白；照片说明使用独立深色阅读面板。窄屏上下分区，相册介绍继续支持折叠。
- 不变更数据库、发布内容或媒体接口。

- 桌面 1280×720：沉浸画布和图片容器均覆盖完整视口，照片 `object-fit: contain`，右侧无背景滚动条；普通模式只有底部一组左右按钮。
