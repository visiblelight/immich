# 登录与文章编辑体验调整

2026-09-18 用户要求优化登录有效期、保存反馈、独立预览、H4 目录、正文间距和页脚。以下为实际实现记录。

## 已实现

- 管理员登录改为 180 天持久会话，仍有效的会话在使用时自动续期，至多每日同步一次到期时间和 Cookie。退出、改密、停用和到期校验保留；已到期的旧会话需要重新登录。
- 保存状态显示数据库记录的最近保存时间（北京时间，精确到秒）。自动保存后再次点击“保存草稿”也会明确反馈；失败和版本冲突继续显示错误，不伪装为成功。
- 编辑页的“独立预览”先完成草稿保存，再进入独立后台预览页面。与前台文章详情共用页面组件，含主导航、目录、正文、相关相册及页脚，提供返回编辑入口。预览需管理员会话且禁止缓存和索引；未发布内容不会开放给公众。
- 正文 H4 从工具栏、粘贴保留、服务端校验到发布渲染和桌面／移动目录完整支持，目录逐级缩进。H5/H6 粘贴归为 H4；旧文档无需转换。
- 正文段后间距由 1.4em 收至 1.1em，H2 上间距由 2.2em（桌面约 55px）收至 1.5em（约 37.5px），H3/H4 保持递减的章节层级。编辑器和前台共用排版。
- 统一页脚上下内边距改为 14px；没有联系链接／附加文字时不会预留空白，存在多行内容时只保留 6px 行间距。

## 验证

- `gallery:check`：零错误、零警告；`gallery:test`：通过；`gallery:build`、`gallery:smoke`：通过。
- `gallery:test:db`：25 项通过，覆盖 180 天会话、旧短会话续期、过期不续期、退出／改密撤销、草稿页面认证、no-store/noindex 和公开版本隔离。Immich schema drift 为零。
- 本地真实后台浏览器：新建临时草稿、粘贴 H2/H3/H4、自动保存、手动保存反馈、刷新后保存时间保持、独立预览进入；桌面目录以及 390px 手机目录的 H4 缩进和锚点跳转通过。浏览器验证发现并修正了离页保护错误阻止预览跳转的问题。
- 本轮不新增数据库迁移。原有 `mise.lock` 用户修改不包含在本次提交。

## 兼容与回退

时间字段沿用 article.updated_at 与 session.expires_at，不改变发布快照和公开发表时间。H4 仍属于现有 schemaVersion 1 的 heading 节点；如果回退到不支持 H4 的旧应用，新文章的后续保存可能被拒绝，应保留 H4 校验与渲染支持。旧会话有效时会自动续期，已经过期则只需重新登录一次。
