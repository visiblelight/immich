# 本地功能 MVP 交付

日期：2026-09-11。用户决定暂缓前后台视觉细节，先完成从选片到公开展示的功能闭环。当前实现已接入本地开发数据库；不是仅内存示例。

## 已实现

- 独立 Gallery 管理员登录、8 小时可撤销会话、改密后全部会话失效、持久化登录限流。
- 独立 Gallery 相册和父子结构，跨 Immich 相册选片、筛选／分页、独立照片文字、顺序与封面。
- 段落、小标题、引用组成的相册介绍；照片保持在照片区，不插入正文。
- 保存草稿、认证预览、首次发布／再发布、父分支下线、恢复原公开版本、删除未发布草稿。
- 版本与树冲突检测，发布失败回滚；不可用来源或损坏预览图拒绝发布。
- 前台固定相册网格、子相册与照片、右侧正文、手机折叠正文、大图翻页／EXIF、静态关于。
- 公开媒体按当前发布关系和来源资格逐次授权；图片重编码为 WebP，移除源 EXIF/GPS/IPTC/XMP；只展示显式允许的相机信息和受限坐标。
- 初次本地接入先做完整数据库备份；前后台使用独立最小权限数据库账号，仅读取指定 Immich 来源，Gallery 写入自身 schema。

## 本轮边界与后续

本地业务闭环可用于实际试用；视觉细节按用户要求后续调整。文字编辑暂不包含行内样式和链接；相册逐本发布、单册数值排序，批量发布／批量排序未做。缺失资源有服务端拒绝和通用提示，专门的批量修复面板未做。关于文章管理、访客功能、地图、独立首页继续不在当前实现。

媒体目前每次鉴权后转换，使用 no-store，尚未加入缓存／并发限流和高并发压测。完整恢复演练、独立 Compose 打包、反向代理／TLS 配置、生产稳定版 Immich 基线与上游升级验收为下一阶段。`productionReady` 保持 false。本轮仅本地提交，不推送远程。

运行入口、初始账号文件位置和重启命令见 [本地 MVP 使用](../development/mvp-local.md)。历史阶段 A/B/C 记录保留，不覆盖其当时的验收边界。
