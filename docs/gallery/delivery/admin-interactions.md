# 后台导航与相册管理交互交付

状态：本地已实现并验证，2026-09-12。已确认规则见 [ADR 0007](../decisions/0007-admin-navigation-and-inventory.md)。

## 已实现

- 后台相册总览显示相册、跨相册去重照片、照片组数量；组成员计入照片数。每行及相册编辑页显示本册直接照片、照片组和子相册数。
- 相册、到访记录、地图设置、站点设置共用稳定导航。移除侧栏最近相册列表；站点设置与个人账号提供独立路由，切页保留未保存修改的离开确认。
- 相册列表按父子关系缩进并可折叠；搜索和状态筛选保留祖先路径并自动展开。手机宽度保留统计与层级。
- 照片组弹窗把照片、排序、封面和成员选择移到标题／共用说明前，沿用已有取消、草稿和单组发布行为。
- 新建相册在应用及实际创建 SQL 中默认精确位置；已有相册、照片和发布快照不修改。本次没有数据库迁移。
- 正式世界地图及区域样稿的未到访国家不再触发悬浮摘要、点击选中颜色或可点击手势，不进入键盘按钮序列。地图平移缩放保持可用。

## 验证

- 根脚本 `gallery:check`：0 errors / 0 warnings；`gallery:build`：前后台生产构建通过。
- `gallery:test`：25 项通过，新增统计去重、相册树折叠／搜索／筛选及位置默认值验证。
- `gallery:test:db`：23 项通过，包括真实 SQL 新建相册默认值、发布权限、GPS、备份恢复及上游兼容验证；Gallery 引入的 Immich 结构差异为 0。使用临时数据库，测试后已清理。
- `gallery:smoke`：前后台在设计开关启用／关闭两种模式下均通过构建启动及无配置拒绝业务就绪检查。
- 浏览器检查真实后台四个页面切换、相册层级与折叠、搜索子相册保留父级、照片组照片与说明顺序；390×844 视口下导航及统计完整显示，无横向溢出。
- 区域样稿与正式世界地图均检查未到访国家点击前后颜色不变、无摘要弹出、无按钮焦点入口。真实手机触控不在本次验收范围。
