# 图文阅读与相册搜索交付

2026-10-17：按 [ADR 0019](../decisions/0019-reading-and-album-search.md) 实施，经过用户视觉验收后已发布生产。下文保留各轮验收记录，最终发布结果见末节。

## 实现

- ArticleReader 内容栏由最多 740px 调整至最多 1100px；桌面目录 240px，整体上限 1380px。文字与图片共用内容栏，不裁剪图片；常见横图可铺满正文，竖图保留高度上限。
- 1000px 及以下使用 48px 吸顶目录栏，展开浮层独立滚动，不推挤正文；章节跳转后关闭，Escape 可关闭并恢复入口焦点。
- 地点面包屑去除末级特大字号，国家条目采用紧凑网格、相邻统计和轻量悬停。
- `/albums?q=关键词` 服务端检索发布投影中的相册、照片、照片组文本及公开地点词典，匹配结果包括发布祖先。按 Unicode NFKC 规范化、不区分大小写的子串匹配，限 120 字符；仅有搜索词时读取照片检索数据，不依赖外部检索服务。当前按完整合资格数据扫描，未来大图库可在保持权限语义前提下优化索引。
- Immich 选片相册名称过滤独立于照片文件名过滤；加载骨架替换旧网格，照片按 Asset ID 绑定，过期响应和错误均被忽略；失败可重试。

## 视觉修订：紧凑工具栏与国家条目

按用户再次确认的样式实施：相册标题与数量留在左侧，右侧 260px 搜索框内置放大镜和清除按钮，输入停顿 350ms 自动检索，中文组合输入完成后才检索，Enter 可立即提交。移除独立搜索按钮，排序改为轻量下拉。搜索更新不滚动页面、不夺走输入焦点。

国家条目使用国家名与统计上下两行，桌面固定 220px 列宽、32px 列间距，手机两列；移除整块悬停底色，仅名称变色。
