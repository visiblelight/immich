# 地点选择与后台到访总览

2026-10-19：用户确认逐级地点选择、切换控件留白和到访表格方案。本轮已完成本地实现与验证，用户验收本地效果后授权提交、推送并发布生产，现已上线。已确认要求分别记录于 ADR 0018 与 ADR 0021。

## 实际行为

- 地点弹层默认仅显示国家；展开按钮独立于地点选中按钮，每次逐级显示省州、城市。选中上级仍包含全部下属照片。
- 搜索自动展开命中地点的祖先路径，搜索中的分支仍能手动开合；清除搜索后恢复浏览时的展开状态。重新打开弹层时仅展开当前已选地点的祖先。
- 共用 SegmentedControl 按内容保留左右 14px 内边距，长标签不压缩；保留浅绿底、白色选中项、原字号和焦点样式。相册排序、相片排序、世界／中国和到访类型切换共用。
- 后台 `/visits` 默认显示所有国家到访，`/visits?scope=region` 默认显示所有中国省级到访。每行一段记录，显示地点、名称、日期、照片数、整理方式／状态和操作；日期倒序、无日期及失效记录排后。
- 支持可选地点、文字与状态筛选，筛选存于 URL，分页每页 20 条；变更筛选回第一页，失效的旧页码自动夹到末页。顶部统计有效到访及地点数，完全失效的人工校正另列数量和入口。
- `adminVisitIndex` 在一个 repeatable-read 授权快照中生成全部摘要，不逐国家重复读取。总览不返回照片 ID 清单、缩略图或原始 Asset ID；点击照片数量、编辑／拆分或合并后，复用受保护的 `/api/visits` 按地点加载照片。
- 编辑按行携带国家／省份及版本，不依赖页面筛选器；只允许勾选同一地点的记录合并。切换筛选或关闭窗口取消未完成读取；从照片查看转入编辑后聚焦名称字段，Escape 关闭并恢复入口焦点。
- 有部分失效照片的人工记录只使用有效证据并标记待核对；完全失效的校正显示为零张、无旧名称和日期，保留版本及清理入口。全局失效入口清除其它筛选，保证入口数量与打开后的范围一致。
- 窄屏的表格在自身容器内横向滚动，不撑宽整页；键盘可聚焦并滚动容器。
