# 图片署名交付

2026-10-21：用户已确认方案、创作者和主页为 `https://vision.ke`；本地验收后已授权提交、推送和生产发布，并要求实际下载 OSS 文件验收。要求见 ADR 0022；迁移数据字典见 `architecture/media-attribution.md`。

## 实现范围

- JPEG / WebP 输出无重编码注入 EXIF 与 XMP，先清除源元数据；后台来源预览、前台相册与文章引用照片、CDN 导出共用同一配置。
- 站点设置新增独立图片署名表单；带并发版本、关闭与恢复能力，保存不触碰相册、照片组和文章发布。
- 新增独立配置表 0014，迁移默认关闭；本地验收阶段另设置用户指定的创作者和主页。生产仍保持原配置与版本。
- CDN 同步写入不含对象地址或密钥的聚合状态，状态过期或策略不一致时不显示完成；后台只读挂载 `public/status`，不获得 CDN 签名配置。
- 云同步增加 `pauseGarbageCollection` 配置，首次生产切换须先停止定时器、更新受审阅 worker 并开启暂停回收，再协调状态目录只读挂载、迁移与应用更新；用户生产验收后恢复回收。此配置不放宽任何访问控制。

## 回退及后续生产发布

本地可关闭“启用图片署名”并保存，无需重新发布。关闭得到与先前相同的无署名字节；相同设置重复应用得到相同内容地址。应用回退可启动原 `visits-ready` 构建，保留新增表，无需删除或恢复业务数据。回退后不能使用缺失 0014 的旧迁移程序覆盖历史。

生产发布须备份、应用 0014、协调新增后台只读状态挂载、安装新版 worker 并开启暂停回收，随后走 GitHub 镜像发布；生产署名设置通过正式后台单独启用，不把本地数据库复制过去。生产验收后解除暂停回收。独立上传的文章素材不自动署名，此范围在设置页明确显示。
