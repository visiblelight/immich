## 生产矢量地图跨域修复（2026-09-27）

生产切换到矢量预设后，AZ/AM 页面出现 `Failed to fetch`。国家照片接口正常；浏览器记录为 OSM 样式请求 `MissingAllowOriginHeader`。
OSM 的样式服务只允许 OSM 与 localhost/127.0.0.1 等开发来源跨域；同一请求在本地成功，在 `https://vision.ke` 失败。上一轮本地英文地图验证与生产 HTTP 页面检查没有覆盖这个差异。

修复内容：

- 从 VersaTiles 官方固定发行版自托管 CC0 样式／图标与 OFL Noto 字体，保留许可证。构建时校验下载包 SHA-256，运行时所有显示资源来自 Gallery 自身域名，地图数据仍直接使用公开支持跨域的 OSM Shortbread 矢量瓦片。
- 后台预设改为本站固定样式路径；已有旧预设自动映射到本站，不改生产数据库配置。任意相对地址仍不允许保存。
- 保留英文优先／当地语言切换、署名、正常缓存和真实 Referer；不使用代理或伪造来源绕过限制，不抓取离线瓦片。
- 矢量样式／资源加载失败时仅尝试一次标准栅格底图，并提示当地语言限制；标准底图也失败则提示重试，照片列表仍可使用。
- 增加生产域名／备用域名／localhost 的资源地址回归、网络及格式异常回退测试，以及构建后样式、拉丁／亚美尼亚字形和图标 HTTP 冒烟。

本次无数据库迁移，不修改 Immich、Edge、JVS 或用户文章／相册。免费地图数据仍依赖 OSM 服务可用性。`gallery:check`、`gallery:test`（50 项）、`gallery:build` 和 `gallery:smoke` 通过。浏览器实测自托管矢量底图显示英文及照片聚合，模拟样式请求失败后标准底图成功接管；测试拦截已撤销。生产验证已完成，见下。
