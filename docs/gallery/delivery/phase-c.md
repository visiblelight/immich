## 本次完成

在现有 Gallery Public 中新增显式开启的 `/design` 评审入口，包含 A/B 两组首页、国家父相册、城市长游记、照片集和边界样例。提供八张 PC／手机关键画面、交互预览、素材许可清单和设计取舍。见[两组方向说明](../design/directions.md)。

本次没有修改 Immich 数据结构或应用现有图库迁移，没有接入真实相册、用户、发布与媒体服务。根页面仍返回 503，运行存活检查 200、就绪检查 503。只有设置 `GALLERY_DESIGN_PREVIEW=1` 才开放设计页；默认 404。设计页使用 no-store 与 noindex。示例静态图片本身是随代码提供的公开授权素材，不靠该开关充当访问控制。
