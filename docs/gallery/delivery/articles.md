# 记录模块交付

2026-09-14。产品范围已确认，视觉评审与真实业务交付分别记录。

## 本阶段

- 已实现样例：记录列表、长文阅读与标题目录、纯文字／关于样稿、图片沉浸浏览；后台列表、标题／摘要／日期／封面／关联相册、Tiptap 富文本、图注直接编辑、示例照片多选和本机图片插入。
- 可操作的样稿流程：IndexedDB 保存文章和插图，刷新恢复；预览当前草稿／发布样稿，模拟发布／更新／下线与关于选篇。浏览器内数据与真实服务端完全隔离，不能视为正式发布功能。
- 已实现内容基础：结构化文章类型、内容白名单与容量／深度限制、链接协议和文字转义、图片引用解析接口、SSR 轻量渲染。公开端不加载 Tiptap。
- 正式站点尚未增加文章入口，样例中的五项导航用于本轮视觉确认；不会把虚构文章混入正式内容。
- 文档：ADR 0012 及文章数据／素材授权设计。
- 本阶段使用虚构文章与既有样例图片；不修改真实相册或照片，不迁移开发数据库。

## 后续

视觉与写作体验评审后，接入文章数据库、素材上传存储、自动保存与并发冲突、发布／下线、关于选篇、相册双向关联及完整隔离验收。样例内任何保存／预览都不是正式发布。
