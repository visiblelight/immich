# Markdown、照片组与时间轴交付

状态：已实现并接入当前本地开发环境，2026-09-11。需求依据为用户确认的 [ADR 0004](../decisions/0004-markdown-photo-groups.md)。本轮不包含首页、地图、文章模块、公网部署及最终视觉定稿。

## 已实现

- 相册正文改为连续 Markdown 编辑，摘要独立且可选；前台缺少摘要时从正文提取。编辑器支持标题、粗体、引用、列表、链接、分隔线、预览、全屏及 .md 导入导出，三种说明共用同一渲染规则。
- 照片描述和组说明同样使用 Markdown。画面描述（无障碍）及向访客展示的位置放入高级设置，解释用途及公开精度限制。原始 HTML、内嵌图片不作为活动内容渲染，链接仅允许 http/https/mailto。
- 大图信息分为作品文字、拍摄日期和位置、折叠的相机参数；手机将文字放在画面下方，横幅照片按原比例显示，避免固定高度的大片留白。
- 一级导航为相册、相片、关于。相片页固定网格，每页 48 张，默认按拍摄时间倒序；可切换首次加入 Gallery 时间倒序，按年月定位，无日期独立分组。当前年月及日期统一按 UTC 显示，不随访客时区变化。
- 相片页从已通过来源、当前发布成员及祖先公开检查的结果中按 Asset 去重；取最早首次发布且当前可见的相册上下文，完整使用该处的文字和公开策略，并提供其他公开相册链接。组内照片在相片页逐张列出，可返回相册查看整组。
- 相册照片及照片组用手柄拖拽排序，也提供前后移动按钮及手柄方向键。成员可以独立排序、换组封面、加入、移出或解散。组占相册一个项目；左右键切项目，上下键和缩略图切成员；放大时方向键移动画面，移动端左右滑动切项目。
- 分组保留每张原有说明、画面描述、独立 EXIF 和实时 GPS；解散或移出时把共用标题和说明保留到成员描述，超出长度限制会明确提示且不执行有损操作。所有操作先改草稿，保存并发布后更新前台。

## 数据与迁移

新增 Gallery 迁移 0004 及 `asset_entry` 表，共 14 张业务表和 1 张迁移记录表。照片草稿／发布成员新增 group_id、description_format；组定义及 Markdown 位于相册 JSON 文档并随发布快照保存。详细类型、长度、索引和权限见 [数据字典](../architecture/database.md)。

旧段落、小标题、引用和简介按文字语义转成 Markdown 读取，保存后写新格式。历史发布文档和照片描述不重写。旧照片 ID、直链、账号及发布状态保持不变。迁移增加相册并发版本，旧打开表单需要重新载入，防止旧客户端覆盖新增字段。

首次加入时间在服务端第一次保存该 Asset 时记录，后续保存、重发、移除再加均不刷新。历史数据只能从现有草稿创建时间及发布记录估算，明确标记为历史估算；不会把 Immich 上传时间当成加入时间。GPS 没有写入快照。

本地应用之前，已将真实数据库备份恢复到独立 PostgreSQL 容器，使用独立角色密码及媒体副本验证旧版本迁移。浏览器创建的照片组和测试文字仅存在隔离副本，未写入用户当前相册。

实际开发库迁移前停止 Gallery 写入、完整备份，然后通过专用 gallery_migrator 运行根脚本 `gallery:db migrate`。备份文件为 `.gallery-local/backups/before-markdown-20260911-230435.dump`（18,522,306 字节，0600，仅本机）。迁移前后核对既有草稿、发布文档、照片文字／顺序及账号凭据摘要一致；2 个相册及 17 条历史发布照片记录保留。Immich 未重启，也未修改它的表结构或媒体文件。

后续部署必须先备份再迁移，运行服务仍只用 gallery_admin / gallery_public。0004 没有原地 down 脚本；回退须在隔离库恢复升级前备份并配合升级前代码验证，先处理升级后的新写入，再制定切换，不能直接用旧代码保存新格式草稿。

## 照片组交互修复（2026-09-11）

用户反馈后在实际 Chrome 复现布局问题：照片列表复用了旧单张编辑弹窗的 `.photo-editor` 全局样式，导致整个列表被拆成两列，再叠加照片网格，将卡片和组编辑区挤窄。组件现使用独立样式名及自适应网格，操作按钮保持完整文字，窄屏下单列；全屏 Markdown 编辑仍相对视口显示。

原实现只有手柄支持拖拽，照片画面本身不会改变顺序。使用手柄执行“第三张移到第二位，再选前两张分组”时，照片 ID 与显示顺序一致；未复现独立的成员身份交换。现允许桌面直接拖照片，提供跟随指针的缩略图、占位、卡片让位动画、边缘滚动和 Esc 取消。排序预览不写入表单内容，松开才应用；按稳定照片 ID 分组并显示已选缩略图，切换相册时重置选择。打开或组成照片组会定位到编辑区。

补充两项回归测试，覆盖第三张移到第二位后的成员身份、先选择再排序、照片组整体移动、组内排序和无效顺序拒绝。`gallery:check` 零错误零警告、`gallery:build` 及 9 项单元测试通过。本次没有数据库或权限变更，沿用此前数据库集成验证。

Chrome 验证包括直接拖照片的占位和松开顺序、分组成员图片来源、组内拖动、Esc 撤销、点击照片编辑、全屏编辑，以及 390px 页面无横向溢出。桌面卡片由故障状态约 117px 恢复至约 245px，390px 窄屏卡片约 328px。测试仅修改独立标签页的未保存表单，没有保存或发布用户相册；用户原标签页的未保存修改保持原样。
