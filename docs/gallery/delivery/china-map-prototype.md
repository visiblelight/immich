# 中国省份抽象地图交互样稿

2026-10-19：依据 [ADR 0021](../decisions/0021-regional-visited-maps.md) 完成第二版本地交互样稿及本机验证。用户已确认样式并授权本地真实数据接入；本文记录样稿阶段，后续业务进展见[真实数据接入记录](regional-visited.md)。

## 本轮目标

- 提供“世界／中国”切换的展示样例，以及 34 个省级地区的原创抽象地图。
- 使用虚构到访地区、照片数量及到访摘要，让用户检查区域方位、标签、小地区点击面积和与现有世界地图的视觉一致性。
- 演示桌面悬浮／键盘聚焦、手机点选面板、地图缩放／拖动／复位，以及进入省份详情的路径。
- 详情只用于说明未来的照片地图交互，不将演示数字或虚构旅行记录混入真实内容。

## 本地入口

- 总览：`/design/visited/china`。
- 福建详情演示：`/design/visited/china?region=CN-FJ`。
- 入口遵循现有 `GALLERY_DESIGN_PREVIEW` 门禁，未启用时不可访问样稿。

## 首版已实现与验证

以下结果对应第二版修订前的首版样稿，不作为第二版的验收结果。

- `china-layout.ts`：原创共享边界多边形，34 个省级地区，西部大块、东北延伸与岛屿单元。京津沪与港澳扩大显示。该几何仅供展示，不能作为真实照片位置归属依据。
- `china-demo.ts`：14 个虚构点亮地区，共 961 张示例照片，示例城市、日期与到访数量；样稿顶部持续显示示例标识。
- `ChinaReview.svelte`：世界／中国切换，金色点亮，与现有世界地图一致；缩放、拖动、全图复位、全屏、键盘导航、地区搜索；桌面直接进入详情，触摸或窄屏先显示摘要和进入按钮。未点亮地区显示空状态。
- `RegionDetailPreview.svelte`：OSM 底图和公开城市中心示意点，点选城市摘要，支持返回与底图失败重试；不请求真实 Gallery 照片或到访 API。真实照片点、大图和到访筛选尚未接入。
- 复用 `World.svelte` 时仅新增默认行为不变的可选链接与标题参数；原国家入口路径保持原样。
- `gallery:check`：全部包 0 错误、0 警告；`gallery:build` 通过；`gallery:test` 62 项通过，其中 3 项验证地区编号、闭合有限坐标、标签落点、最小几何尺寸及多边形无面积重叠。
- `gallery:smoke` 通过；新增总览、地区详情和世界切换路径的设计预览门禁检查。关闭门禁返回 404，开启返回 200，并包含 `no-store`、`noindex, nofollow`。
- 本机浏览器验证：桌面与 390×844 窄屏、世界切换、福建详情／返回、未点亮摘要、搜索、键盘缩放／平移／聚焦摘要、鼠标拖动不误跳转、全屏进入退出。福建 OSM 底图实际加载成功，未捕获浏览器错误。
- 窄屏确认无横向溢出；完整地图用于总览，小地区可放大或通过搜索定位。真实手机双指手势仍待用户设备体验，不将鼠标窄屏检查视为真机验收。
- 本机截图位于忽略目录 `.gallery-local/china-prototype/desktop.png` 和 `mobile.png`。

## 第二版已实现与验证

以下调整已实现，用户已确认：

- 统一“去过”和“尚未留下照片”的页面文案；没有照片不等同于确定未到访。
- 国家／省份搜索共用现有相册搜索基线组件，保持输入、图标、边框与清除操作一致。
- 世界／中国切换沿用相册／相片排序组件的浅绿底、白色选中项样式。
- 简化地图几何，以矩形、梯形为主，多数地区为 4–6 个折角；删去锯齿和碎折线，提高东部可读性并减少西部无效留白。
- 地图保留 34 个区域、共 188 个顶点；25 个区域不超过 6 个折角，最多 8 个。最小原生尺寸为 36 地图单位，小地区仍建议在窄屏放大后选择，也可通过搜索找到。
- 抽出 `SearchField` 和 `SegmentedControl` 共用组件，相册搜索、相册／相片排序及国家／省份入口复用；两张地图复用同一个图例，统一去过区域的金色标识。
- `gallery:test` 63 项通过，包含 34 个区域、标签落点、无面积重叠及几何简化约束；`gallery:check` 全部包 0 错误、0 警告。
- 使用 `GALLERY_BUILD_SUBDIR=china-review` 运行 `gallery:build` 和 `gallery:smoke` 均通过；设计预览关闭时返回 404，开启时样稿路由可访问，保持 no-store/noindex。
- 本机浏览器验证 1365×960 桌面与 390×844 窄屏；省份／国家搜索与清除、范围切换、福建详情／返回、香港及海南摘要、缩放／全图复位、全屏进入退出、鼠标拖动不误跳转均正常。窄屏无横向溢出。
- 国家、省份及相册搜索框均为 38px 高、12px 字体、6px 圆角，使用相同边框样式；相册自动搜索、清除和排序保留关键词，以及相片最近加入排序经过浏览器回归验证。
- 本轮浏览器未捕获错误；真实手机双指手势仍待设备体验，窄屏鼠标点选不代表真机验收。
- 第二版截图保存于忽略目录 `.gallery-local/china-prototype/desktop-v2.png` 和 `mobile-v2.png`。

第二版本身仍是标明示例数据的对照样稿。用户已确认视觉效果，真实省界、统计及完整业务在独立正式路由接入，见[实现记录](regional-visited.md)；尚未发布生产。
