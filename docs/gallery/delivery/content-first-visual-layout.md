# 内容优先视觉调整交付

2026-09-13。依据 [ADR 0011](../decisions/0011-content-first-visual-layout.md)。

## 实现

- `PublicHeader` 统一相册、相片、关于及世界/国家地图页头，统一字体、背景、选择器及焦点样式。
- 桌面相片筛选集中左栏；窄屏默认收起。标签交集、排序、年月和分页仍通过 URL 保留。
- 目录标题收紧，相册中有直接照片时将子相册改为紧凑卡片。
- 照片阅读区与图像画布留出间距；拍摄地点与参数直接展示，拍摄参数按稳定顺序排列。沉浸退出、左右项目及上下组内切换保留。
- 后台照片、子相册、介绍、设置分开；发布概况收为展开入口。照片卡片常驻更多菜单，悬浮/键盘聚焦显示叠加工具，触屏常驻拖动与选择工具。
- 批量工具在选中后出现；组编辑去掉重复标题，缩减照片卡片操作区域。站点联系链接独立成行，保存按钮覆盖整个表单。

- 相片、去过、关于页在 1280px 窗口中页头均为 80px，同一左右边界；背景和字体一致。
- 同一 1280×720 窗口，相片第一排由顶部约 450px 提前至约 207px。
- 后台照片区在该宽度由两列变为三列；无子相册不再占据照片标签的空面板。
- 浏览器验证标签筛选、批量选择与清除、操作菜单、联系链接行及沉浸查看。

- 最终 `gallery:check`：0 错误、0 警告；`gallery:build` 成功。
