## 当前页面和操作

| 页面 | 桌面 | 手机 |
|---|---|---|
| 相册目录 | 固定四列网格；平板过渡三列；统一封面比例 | 固定两列，不用瀑布流 |
| 相册详情 | 左侧分组展示子相册和本册照片，右侧约 310–350 px 的文字介绍 | 子相册与照片两列；介绍区域默认折叠、点开阅读 |
| 看图器 | 完整照片尽可能占据屏幕；右侧标题、描述和 EXIF 可隐藏 | 默认全宽看图，信息按需展开为下方可滚动区域 |
| 关于 | 正文列宽受控的静态文章 | 同一篇内容，适配窄屏 |

相册封面用统一 4:3 容器裁切；直接照片的固定网格也采用 4:3 图位，但图片完整适应容器，横竖照片不会因列表裁切丢掉画面。点击后看完整大图。相册介绍使用标题、段落和引用等文字排版，不包含图片。

看图器支持上一张／下一张、左右键、Esc 和关闭按钮；关闭后焦点返回触发照片。隐藏信息时照片区使用整个可用宽度。照片信息中的参数明确标为“示例”，不是这些素材的实际 EXIF；实际接入时读取 Immich 允许公开的相机参数，不自动输出 GPS 和整份原始 EXIF。

示例包括：六个顶级相册；格鲁吉亚同时包含两个子相册和六张直接照片；城市札记只有子相册；格鲁吉亚 → 第比利斯 → 索洛拉基展示三级关系。相册之间复用照片以演示同一 Asset 的不同收录，不增加或访问私人图库。

## 验证与局限

- `gallery:check` 通过，Svelte 0 错误、0 警告；`gallery:build` 通过。
- `gallery:smoke` 通过：目录、并存相册、纯父相册和关于页启用时返回 200，设计开关关闭时返回 404，非法相册／页面参数返回 404。普通前台根地址仍为未开放状态。
- 浏览器按 320／390／768／1280／1920 CSS px 检查五类页面，共 25 组；无横向文档溢出、已加载图片无失败，导航仅两项，介绍无图片。
- 已操作手机介绍展开／收起、照片信息显示／隐藏、左右键、Esc 和焦点返回；桌面隐藏参数时照片区域扩展到视口全宽。
- 本轮没有改数据库或产品依赖；没有接真实文章、编辑器、EXIF 或发布数据。照片深链接、缩放／手势、真机浏览器和大量照片性能保留到正式公共体验阶段验收。

布局反馈重点是相册密度、左右分区比例和手机介绍的展开方式，不再进行画册／展览风格二选一。
