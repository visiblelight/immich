# 视觉设计交付说明

状态：产品方向按用户反馈修订；新版具体画面待评审。版本：0.2，2026-09-11。

## 目标

清晰、克制、以相册和照片浏览为中心。通过整齐的网格、可读的字号、适量留白和明确的信息层级保证质量。此前画册／展览方向不作为后续实现依据，范围调整见 [ADR 0002](../decisions/0002-albums-first.md)。

## 本轮页面

- 一级导航只有“相册”“关于”，入口直接展示相册网格；首页暂缓，地图不在 MVP。
- 相册目录：固定列数，不做瀑布流；桌面四列、平板三列、手机两列为当前预览方案。
- 相册详情：左侧子相册和直接照片，右侧详细介绍；富文本仅包含标题、段落、列表、引用、强调和安全链接，不插图。
- 手机详情：同一内容层级，子相册和照片两列；长介绍置于可展开区域，避免首次打开先滚过整篇游记。
- 看图器：尽可能大的完整照片、标题、描述及 EXIF 信息；信息区可以隐藏。手机默认收起参数，需要时展开。
- 关于：静态文章示例，未来由后台文章模块选篇展示。本轮不设计或实现文章管理后台与数据库。

## 验收维度

| 维度 | 标准 |
|---|---|
| 网格 | 同一断点列数固定，相册封面统一比例；不使用瀑布流或错落展览布局 |
| 图片 | 封面可有焦点裁切，照片列表和看图器保持完整画面；横竖都可浏览 |
| 文字 | 相册详细介绍与照片分区；长文有清楚段落，不在介绍中重复插图 |
| 层级 | 子相册与直接照片分组；面包屑能返回各层；纯父相册不会展示所有后代照片 |
| 响应式 | 320／390／768／1280／1920 CSS px，无横向页面溢出；移动介绍和照片信息可展开 |
| 看图器 | 充分使用视口，参数区不迫使图片缩成小预览；键盘切换、关闭、焦点返回 |
| 可访问性 | 按钮有名称、图片 alt、焦点可见、原生对话框管理焦点，支持减少动态效果 |
| 状态与性能 | 后续真实数据接入验收加载、错误、无内容、资源失效；按需取图与响应式图片 |

使用“子相册与直接照片并存”“纯父相册”“多级相册”“长文字”“横竖照片”样例。预览照片、介绍和 EXIF 示意值应明确区别于用户的真实内容。

当前预览与交付记录见[相册浏览布局](album-browser.md)。旧 [A/B 方向](directions.md)仅作历史记录。正式业务、文章模块和完整真机手势需要后续验证，预览不等于生产实现。
