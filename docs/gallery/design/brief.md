# 视觉设计交付说明

状态：已确认。版本：0.1，2026-09-10。

## 目标

简洁、具有摄影画册与编辑式排版的设计感。照片、文字和留白共同形成阅读节奏；MVP 控制功能数量，但视觉和交互完成度属于核心交付。

## 设计阶段的产物

1. 两组视觉方向，每组包含 PC 首页、PC 相册详情、移动首页、移动相册详情的关键画面。
2. 每组说明字体层级、色彩、留白、照片比例、封面裁切、游记双图与子相册入口的组织方式。
3. 用户选定方向后，完成看图器、地图、后台编辑页关键交互稿，并建立 Gallery 自己的组件规范。
4. 使用浏览器可交互原型和实际尺寸检查。文档中的方向描述不替代真实视觉验收。

工程初始化和只读适配验证可在视觉确认期间继续；完整公共页面开发以选定方向为基础。

## 拟探索的两组方向

- 摄影画册：纸感中性色、舒展留白、克制标题、以完整画面和阅读为中心。
- 当代摄影展：清晰网格、更有力量的字号对比、节奏鲜明的作品与系列入口。

两组都需真实呈现多级相册和较长游记，不以单张漂亮的 Hero 图代替完整产品设计。不引入未经许可的远程字体或付费素材依赖。

## 验收维度

| 维度 | 标准 |
|---|---|
| 图片 | 正文与看图器默认保持完整比例；封面裁切有焦点控制；明暗、横竖图都可用 |
| 排版 | 中文、英文和混排可读；正文列宽受控；长标题、长图注不挤压按钮 |
| 层级 | 用户能分辨父级游记、子相册与直接照片，面包屑不制造重复导航 |
| 移动 | 专门设计首屏与操作位置；320 CSS px 至常见大屏手机无横向溢出 |
| 桌面 | 1280 与 1920 CSS px 下保持内容比例；平板过渡布局可用 |
| 可访问性 | 键盘可操作、焦点可见、对话框焦点管理、图片 alt、减少动态效果 |
| 动效 | 用于过渡和反馈，不延迟主要内容，不自动播放干扰阅读 |
| 状态 | 骨架／占位、空内容、无坐标、失效资源、网络失败均有明确设计 |
| 性能 | 不为移动首屏下载整组桌面大图；图片声明尺寸，减少布局跳动 |

使用至少三种内容样例：纯父相册、长游记混排相册、包含大量照片的相册。素材优先采用用户允许用于该原型的照片；未发布的真实素材只在本地或受认证预览中使用。

底图供应商、字体与编辑器依赖在本阶段核实官方使用条件和可用性并记录选择。地图必须保留供应商要求的署名。视觉方案获确认后再收敛成单一主题，MVP 不实现主题切换。
