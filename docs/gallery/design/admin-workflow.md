# Gallery 后台：相册工作台交互预览

状态：后台页面与核心流程原型完成，待用户评审；真实后台业务尚未接入。2026-09-11。

用户已决定暂时保留当前前台布局，视觉细节后续调整，优先验证整体流程闭环。这不是前台最终视觉验收。

[打开后台预览](http://127.0.0.1:3101/design)。启动命令：

```sh
sh deployment/gallery/scripts/pnpm.sh gallery:design:admin
```

所有操作仅改变当前页面内存，刷新或开发热更新会恢复示例。没有真实登录、数据库写入、Immich 请求或向前台 3100 发布内容。使用独立的 3101 端口，正式根地址仍返回未开放状态；设计入口需显式开启 `GALLERY_DESIGN_PREVIEW=1`。

## 页面与工作流

| 页面 / 工作区 | 本轮可操作内容 |
|---|---|
| 相册列表 | 草稿树、分支筛选、标题搜索、发布状态筛选、照片与子相册数量、新建相册 |
| 照片与子相册 | 新建子相册、进入子相册、添加与移除照片、前后排序、设封面 |
| Immich 选片弹窗 | 跨来源相册多选、文件名 / 标签 / 起始日期筛选、翻页、清空选择；已加入与不可用照片禁选 |
| 照片编辑 | Gallery 独立标题、描述、替代文本、位置公开策略；来源和 EXIF 为只读示例 |
| 相册介绍 | 简介、段落、小标题、引用文字块；不含图片。完整富文本编辑器后续接入 |
| 基本设置 | 标题、slug、父级、封面；首次发布后锁定 slug；排除自己与草稿 / 公开后代作为父级 |
| 预览 | 当前编辑内容与公开快照分别查看；左侧子相册和照片、右侧介绍；手机介绍折叠；点击照片看大图和文案 |
| 发布确认 | 选片 / 顺序、照片文案、介绍、封面、父级变化提示；标题、地址、资源、层级检查；保存并模拟发布当前相册 |
| 下线 / 恢复 | 按公开树展示受影响后代；恢复旧公开版本不发布草稿，不恢复单独下线的子相册 |
| 站点设置 | 名称与简介保存并应用；展示三个域名的配置示例；文章选篇后续单独设计 |
| 个人账号 / 登录 | 修改演示显示名称、退出与进入演示；不收集真实密码 |

原型入口集中在 `/design`，内部切换工作区。正式页面路由、接口与权限将在业务实现中建立。

## 建议评审故事

1. 新建「格鲁吉亚旅行精选」，从「第比利斯」选一张，再切换「巴统与黑海」选一张。选择应保留，最终加入同一本 Gallery 相册。
2. 给照片写标题与描述，调整顺序、设置封面；写一段相册介绍，保存草稿。
3. 查看草稿预览，确认模拟发布；再改简介，打开已发布效果，确认线上快照仍是原文。
4. 下线「格鲁吉亚」，确认「第比利斯」和「索洛拉基」都不可访问；将索洛拉基单独下线，再恢复格鲁吉亚，确认索洛拉基保持下线。
5. 将未发布相册设为父级，尝试发布子相册，应提示先公开父相册。

## 设计与实现边界

- 后台以内容操作效率为主：浅色工作区、固定导航、相册表格、编辑标签页、右侧发布概况。没有展览式首页，也不新增地图或文章模块。
- 原型有编辑态、保存草稿和公开快照三个对象。切换工作区保留当前编辑态；刷新会丢失全部演示更改。真实保存、并发版本冲突与离开提醒属于业务实现。
- 同一资产在不同 Gallery 相册的文字互相独立。新选入照片的标题 / 描述为空，不导入 Immich 文案。
- 位置默认隐藏；精确 / 近似选项用于确认交互位置。当前不模拟真实坐标、脱敏计算或同步；接入时沿用已批准的 Immich GPS 实时读取规则。
- 单次只发布当前相册，要求父级已公开；不假装完成批量发布事务。相册同级排序、完整富文本工具、从后代选择父相册封面、资源失效实时刷新和批量操作尚未实现。
- 预览为布局模拟：子相册显示封面示意；大图使用已有示例缩略图。正式后台预览与公共页面需提取共享渲染组件，接入受控大图、跨页导航与发布接口。此时仍需完成真实媒体授权验收。
- 登录是显式「进入演示」，真实密码修改、账号停用、会话撤销、CSRF 与限流尚未实现，不能部署为可用管理后台。
- 复用前台六张授权示例照片，小图按原图缩放；作者与许可在页面「使用说明与素材署名」中完整列出。日期、分类、地名与 EXIF 均为演示数据。

## 验证记录

- `gallery:check` 通过（Svelte 0 错误、0 警告），`gallery:build` 与 `gallery:smoke` 通过。前后台正式根地址和 readiness 均为 503；设计开关关闭时 `/design` 返回 404，开启时为 200，包含 no-store / noindex 响应头。
- 浏览器已实际操作跨相册选择、独立照片文案、文字块编辑、保存、发布、公开快照隔离、父级下线、恢复与单独下线后代保留。
- 浏览器按 320 / 390 / 768 / 1280 / 1920 CSS px 检查列表、编辑、选片、预览共 20 组，文档及弹窗均无横向溢出；已检查的图片无加载失败。手机介绍展开、选片跨页保留、父级未公开阻止发布、站点保存和退出 / 进入演示均实际操作通过。
- Immich API 2283、后台 3000 和 Gallery 前台 3100 均返回 200。本轮无依赖安装、数据库变更或容器重启。
- 真机、长相册性能、服务端事务与权限检查仍留在业务验收阶段。

当前没有阻塞继续设计的产品问题。评审重点是操作顺序、选片方式、编辑分区与发布提示；通过后再接入真实登录、资源查询和持久化。
