# 两种观看方式：阶段 C 视觉评审

状态：两组可交互方案已制作，等待用户选定方向。2026-09-11。

## 打开与比较

在仓库根目录运行：

```sh
sh deployment/gallery/scripts/pnpm.sh gallery:design
```

打开 [本地方案对比](http://127.0.0.1:3100/design)。可以切换 A/B、首页／国家相册／城市游记／照片集／边界状态，并选择预览宽度。独立打开能获得完整浏览器高度。启动命令只监听本机 127.0.0.1:3100；不是公网地址。

两组使用相同的六张授权示例照片和虚构游记。临时站名“行间”“别处”也是设计元素，不是已确认品牌。方案切换只用于本次评审，正式 MVP 收敛为一个主题。

## 方向比较

| 项目 | A：摄影画册 | B：当代摄影展 |
|---|---|---|
| 气质 | 温和、安静，让照片与游记共同成为内容 | 清晰、有力量，先看见作品与系列 |
| 首页构图 | 左侧引言、右侧竖向封面；下方相册错落排布 | 大字开篇、宽幅封面与黑色展签；相册沿网格排列 |
| 标题字体 | 本地中文宋体，正常字重 | 本地无衬线，较强字重与紧凑字距 |
| 主色 | 纸白 `#f5f3ed`、墨绿 `#343a31`、辅助文字 `#68705f`、橄榄绿 `#526142` | 展墙白 `#fdfdfb`、近黑 `#1d201f`、辅助文字 `#676d69`、朱红 `#e44d26` |
| 桌面主标题 | 首页约 46–80 px；相册约 40–72 px | 首页约 70–166 px；相册约 44–100 px |
| 移动主标题 | 首页 40 px，游记通常 35 px；小屏再缩小 | 首页大字，游记通常 42 px；小屏 36 px |
| 正文 | 桌面 17 px，约 2.25 倍行高 | 桌面 17 px，约 2.1 倍行高 |
| 留白与阅读 | 正文窄栏、边注、错落双图，段落之间留出停顿 | 正文窄栏、清楚章节、对齐双图，节奏更紧凑 |
| 照片与封面 | 正文保持完整比例；封面容器按版式裁切 | 正文保持完整比例；首页采用更宽的封面 |

公共内容区桌面左右通常留 60 px，最大宽度 1600 px；平板缩至 36 px，手机 20 px。两组都用 690–700 px 左右的正文宽度上限。移动端重新排列引言、图片和相册信息，不沿用桌面缩小版。

封面目前采用固定示例焦点 `50% 48%`；正式后台的焦点编辑和保存尚未实现。正文横竖图与看图器使用完整画面，选择封面不改变原始文件。

## 内容与交互样例

- **纯父相册**：格鲁吉亚有自己的总体游记和两个子相册，明确标出 0 张直接照片。封面与直接照片数分开理解。
- **长游记相册**：第比利斯展示章节、长段落、横竖双图、引文、子相册与本册照片。可进入“索洛拉基”第三层，面包屑能返回父级。第三层复用示例内容，只演示层级导航。
- **照片集**：巴统用两张海岸素材重复构成 36 个示例图位，12 → 24 → 36 逐组显示，可切网格／大图。重复图位不是 36 个独立 Asset；看图器只在两张示例作品之间切换。
- **基础看图器**：打开完整图片和独立标题描述，按钮／左右键切换，Esc 关闭，焦点返回触发照片。原生 dialog 限定焦点，打开时锁住页面滚动。
- **边界状态**：空相册、无公开位置、失效照片、404、加载占位和网络中断。它们是视觉样例，不代表已接入实际错误恢复或发布状态。
- **比较工具**：说明面板支持键盘关闭；素材署名页可独立查看。

静态文件在 `packages/gallery-public/static/design-assets/`，JPEG 仅缩放与压缩；800 px 宽的副本用于响应式 `srcset`。封面裁切由 CSS 完成，正文不裁切，没有使用私人图库或连接 Immich。原型照片不能在正式站点中被表述为用户自己的作品。
